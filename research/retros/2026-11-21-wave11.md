# Retro: wave 11 port selection

**What happened.** Wave 11 picked the 24 newest unported problems in the
source repo. Fourteen had no accepted submission by the author on
Codeforces: the repo also keeps unfinished drafts and empty templates. One
port agent spent its run proving four of its six originals were drafts.

**Change.** Problems are now picked by `scripts/pick-ports.py`, which keeps
only problems with an accepted verdict and a non-trivial original that
prints output. Port briefs also ask agents to check the original passes the
samples before porting. Affected sessions got verified replacements.

**Why it is general.** Any corpus drawn from a public solutions repo has
drafts; the accepted verdict is the only trustworthy filter.
