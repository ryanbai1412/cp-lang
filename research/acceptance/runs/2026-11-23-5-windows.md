## 1. understand (1 min, pass)
CPL is a Python-indented contest language that compiles to one readable, self-contained C++17 file you submit as GNU C++17. It does better than C++ by making the statement's constraints the types (`1..=2e5` is checked on read and picks the width), by typed index spaces (`domain V = 1..=n`) that remove `-1` off-by-ones and mix-ups between vertex/edge indices, and by `?T` optionals instead of `-1`/INF sentinels. It also ships a contest stdlib (segtree, DSU, Dijkstra, Mod) plus built-in stress testing with shrinking and a time-travel trace debugger in the same file. Read /learn/intro, cheat sheet, tour, getting-started, idioms. Hesitation: idioms guide recommends a manual lo/hi binary search; intro says `first_true` replaces it.
