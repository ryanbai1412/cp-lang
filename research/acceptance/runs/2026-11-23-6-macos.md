**1. understand (2 min, pass).** I read the getting-started guide, tour and cheat sheet on cp-lang.org. CPL is a language for competitive programming that compiles one readable source file to one self-contained C++17 file you can submit to any judge. It removes the boilerplate (main, includes, fast I/O, multitest loops) and lets you write input constraints as types, which then drive validation, integer widths, index safety and generated stress tests. Compared with C++ it catches the usual contest bugs (off-by-one, wrong index space, overflow, aliasing) at compile time or as a trap with a message, and it ships brute-force stress testing, shrinking and traces in the toolchain.
