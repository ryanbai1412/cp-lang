## 1. understand (4 min)
Read https://cp-lang.org, /learn/intro/, /docs/guides/getting-started, the cheat sheet and /setup/. My three sentences: CPL is a contest language that you write like typed Python and that compiles to one readable C++17 file you can submit to Codeforces. It does better than C++ by putting the input constraints in the types (`let n: 1..=2e5 = read()`, `[0..n]` domains), so reading input, overflow-safe integer widths and index bounds come for free and are checked. It also ships the contest loop (samples as tests, `cpl stress` against a brute with shrinking and traces, judge profiles) and a contest stdlib (segment trees, DSU, Dijkstra, modular ints) so there is no template to paste.
