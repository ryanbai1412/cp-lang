# cf2159e — Super-Sum

Score: 4/5
Dream: 4/5

Short and close to the editorial: `p^n = p^j * p^(iB)`, small powers kept
whole, large powers as prefix sums, coefficients from the `p * f' = n * p' * f`
recurrence. The two comments (lines 9, 18) carry the idea; a one-line
header naming the problem should open the file.

## Checklist failures

- No header (line 1 starts with `type Z`).
- Tables built on first use behind `len == 0` sentinels (lines 19-20,
  27-28). Reported.
- Decoded `n` is never bounded (line 25): `0..=N` would validate the
  decode and prove `i <= N / B`. The dream reads it as `0..=N`.
- Block size changed from the original's to fit 64-bit `Mod` storage
  (line 3). Reported.

## Owed rewrites

- Add the header line.

## Language gaps

Reported: 64-bit `Mod` storage, lazy tables, `read(xor:)`, the lint that
unrolls the recurrence, `List.map`. Not reported: `Poly<Z>` with `^`
(dream lines 5, 7); the port builds `small[j]` with the same `coeffs`
recurrence as `big`, which works, but the report should say the stdlib
has no polynomial power.

report. `prefix(f)` and `big[i].upto(k - z + 1)` name the same prefix sum
two ways; one name across the dreams (`prefix_sums`, as in `cf2183h`).
