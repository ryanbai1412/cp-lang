# cf2207e1 — Prefix Max Restore (easy)

Both reject a non-increasing or out-of-range `a`, then walk `i` from `n` down, pushing every
value up to the current bound on a stack and popping one per position.

## The port dodges a one-element concatenation
- **Where:** dream `let bounds = [n] + a` and `let cur = bounds[i]`; port
  `let cur = if i == 0: n else: a[i - 1]`.
- **What:** the port avoids copying `a` into a new list, but the dream form is not slower
  (12 ms vs 15 ms on `--max`, same output). The port's branch is an index shift a reader has to
  check. Owed rewrite to the dream's line.
- **Goal it hurts:** express (R2).
- **Severity:** low.
- **Owner:** idioms.

## Validity check spelling
The dream writes `any(... for i in ...)`; the port `(0..n - 1).any(i => ...)`. Both are
current; the free generator form reads like the statement's "if any". No gap.
