# cf2135e1 friction

The port is the dream, with one spelling forced by inference.

## A literal base of `**` does not take the result's type

- **Goal it hurts:** hard-to-get-wrong
- **Severity:** medium
- **Area:** core
- **Status:** open
- **Dream:** `proto/ports/ecnerwala/dream/cf2135e1.cp` last line, which was
  `print(2 ** n - bad)` with `bad: M`.
- **Actual:** `2 ** n` types as `Int ** Int`, overflows for n >= 63 and only
  then meets `M`; the port writes `M(2) ** n`.
- **General fix:** a literal operand takes its type from the other operand
  or the expected type of the whole expression (as `M(2) * x` already does),
  so `2 ** n - bad` is computed in `M`.

## Measurement

Three tests n = 200,000, 199,999, 123,457, `g++ -O2`: 0.02-0.03 s vs
0.12-0.13 s for the old reflection port, same output. Emitted C++ 21,162 ->
18,889 bytes.
