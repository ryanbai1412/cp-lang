## Frictions (port vs dream)

### 1. No `max_subarray(widest:)` that returns the segment (`dream/cf2066f.cp:24`)
- **Severity:** medium
- **Goal it hurts:** express and revise
- **Where:** the port hand-writes Kadane as `widest_max` (tie-broken to the widest segment) because `MaxSub` folds only the sums, never where the best segment lies.
- **General fix:** a slice fold that returns the arg range of the best subarray (`a[r].max_subarray(widest: true) -> Range<D>`), and `max_subarray_sum()` beside it.

### 2. A list can't introduce its own index domain (`dream/cf2066f.cp:27`)
- **Severity:** low
- **Goal it hurts:** express and revise
- **Where:** `let spans = cool(...)`, then `domain Seg = 0..spans.len` and `let span = [Seg] s => spans[s.ord]`: three lines and an `ord` round trip for "number the segments".
- **General fix:** `list.indexed()` returning a fresh domain and the array over it, the same mechanism compression and grouping would use.

### 3. Cut arithmetic and slice comparison (`dream/cf2066f.cp:44-45`)
- **Severity:** medium
- **Goal it hurts:** express and revise, hard to get wrong
- **Where:** `b[j..].starts_with(a[span[s]])` and `j + span[s].len` on a `PosB.bounds` cut don't exist, so the port precomputes `agree[i, j]` (common run lengths) and steps with `PosB.bounds.nth(j.ord + len)`. The table is also faster, so only the cut step is a real gap.
- **General fix:** offset a cut by an `Int` (`j + k`, an optional or trapping step like `.fwd`), and element-wise `==`/`starts_with` on `[D]T` slices across domains.

### 4. No `first_some` on lists (`dream/cf2066f.cp:67`)
- **Severity:** low
- **Goal it hurts:** express and revise
- **Where:** the port wraps the threshold search in `fn first_plan() -> ?(Int, Plan)` with a `for` and an early `return`.
- **General fix:** `first_some(f)` / `find_map` on every sequence: the first `some` an `?T`-valued function returns.

### 5. `PosB.bounds` can't be aliased (`dream/cf2066f.cp:29`)
- **Severity:** low
- **Goal it hurts:** express and revise
- **Where:** `type CutB = PosB.bounds` is a different type from `PosB.bounds`, so `PosB.bounds` is spelled out a dozen times.
- **General fix:** a `type` alias of a domain's cut type should be the same type and expose its static members.
