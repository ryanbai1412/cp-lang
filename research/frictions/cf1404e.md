Ported `cf1404e` (`n, m <= 200` grid of `#`/`.`, minimum axis-aligned 1×k / k×1 bricks covering all `#` cells) by formulating cell orientation (horizontal = S-side, vertical = T-side) as an S-T minimum cut solved with `std.flow.FlowGraph`.

- Gate: `proto/ports/ecnerwala/gate.sh cf1404e 150` passed (`PASS cf1404e (3 samples, 150 random cases)`).

## `FlowGraph` requires flat integer node domains and lacks `min_cut` alias

- **Severity:** medium
- **Goal it hurts:** express
- **Area:** flows (`plan/STDLIB.md`) + core language
- **Dream lines:** `proto/ports/ecnerwala/dream/cf1404e.cp:12-21`
- **What happened:** `FlowGraph` only accepts a 1D integer domain `Node = 0..n * m + 2`, forcing manual flattening (`fn cell(r, c) = Node(r.ord * m + c.ord)`) and synthetic `src = Node(n * m)`, `snk = Node(n * m + 1)`. There is also no `fg.min_cut(src, snk)` method naming the min-cut objective directly.
- **General fix:** Support finite product/sum domains (e.g., `enum Node { Src, Snk, Cell(Row, Col) }`) as domain keys in `FlowGraph`, and provide `min_cut(src, snk)` alongside `max_flow(src, snk)`.

## No 2D `[Row, Col]Char = read()` grid input or product-domain iteration

- **Severity:** medium
- **Goal it hurts:** express
- **Area:** core language / I/O
- **Dream lines:** `proto/ports/ecnerwala/dream/cf1404e.cp:10, 14`
- **What happened:** Reading a character grid into `[Row, Col]Char` is not supported, so the port reads `rows: [Row]Str` and indexes `rows[r][c.ord]` with manual `.ord` casts. Product iteration `for (r, c) in (Row, Col)` is also unavailable, requiring nested loops.
- **General fix:** Allow `read()` to populate `[Row, Col]Char` from `Row` whitespace-delimited strings, and support product iteration `for (r, c) in (Row, Col)`.

## No guarded `if let` expression (`if let rp = r.prev if ...:`)

- **Severity:** low
- **Goal it hurts:** express
- **Area:** core language
- **Dream lines:** `proto/ports/ecnerwala/dream/cf1404e.cp:16-17`
- **What happened:** Combining optional unwrapping with a boolean guard inside an expression (`if let rp = r.prev if grid[rp, c] == '#': ... else: ...`) does not parse, forcing mutable `var up = src` and two nested `if` statements.
- **General fix:** Support chained conditions in `if let` expressions (`if let x = opt and cond: ... else: ...`).

## An enum with domain payloads is not an index domain

- **Severity:** medium
- **Status:** accepted (sum domains, the dual of product domains §88); owned by the fresh-domains lane
- **Goal it hurts:** express, hard to get wrong
- **Area:** core (domains)
- **Dream lines:** `proto/ports/ecnerwala/dream/cf1404e.cp:22-30`
- **What happened:** `enum Node: Src / Snk / Cell(Row, Col)` names the flow network's vertices, but `FlowGraph<Node>()` fails ("doesn't know the name `V`", "indexed by `Int`, but the index is a `Node`"). The port hand-encodes `Node(r.ord * m + c.ord)` with `src = Node(n * m)` and `snk = Node(n * m + 1)`.
- **General fix:** an enum whose variants are fieldless or carry only index-domain payloads is a finite index domain with dense `.ord` in declaration order, usable wherever a domain is (`[Node]T`, `for v in Node`, `FlowGraph<Node>`, `Dsu<Node>`).
