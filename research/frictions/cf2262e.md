# cf2262e — Catalan Shifts

Both raise the symbol series `C(i-1)^2` to successive powers by `convolve`, truncated to `n + 2`
terms, then alternate-sum binomials for each shift.

## The port truncates in place
- **Where:** dream `cur = convolve(cur, symbol)[..n + 2].to_list()`; port
  `cur = convolve(cur, symbol)` then `cur.truncate(n + 2)`.
- **What:** the dream's slice-then-copy allocates a second list per power; the port's truncate
  doesn't (35 ms vs 34 ms on `--max`, same output, so it doesn't matter here). A
  `convolve(a, b, len:)` would say "first `n + 2` terms" in the call and let NTT size itself.
- **General fix:** `convolve(..., len:)` in `std.ntt`.
- **Severity:** low.
- **Owner:** stdlib (ntt).

## Literals in `Mod` branches
The port writes `Z(0)`/`Z(1)` where the dream's bare `0`/`1` check today. Owed rewrite; owner idioms.
