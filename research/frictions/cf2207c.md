# cf2207c friction report

The hand-built Cartesian tree is gone: `port.cp` roots `std.tree.cartesian_tree` with
`Rooted.from_parents` and reads the column run of a node as `t.size(u)`.

## The max-Cartesian tree is spelled twice, neither with `by: desc`
- **Where:** `port.cp` line 16, `use std.tree.{cartesian_tree}` (line 12) and
  `Rooted.from_parents(cartesian_tree(a, by: (x, y) => x > y))`.
- **What felt wrong:** two `cartesian_tree`s exist: `std.seq`'s method
  `a.cartesian_tree(min_root: false)` (root, left, right, parent arrays) and `std.tree`'s free
  `cartesian_tree(a, by:)` with a comparator. Neither takes the one order flip,
  `by: desc`: `cartesian_tree(a, by: desc)` is E0302 "takes a fn(Int, Int) -> Bool for `by`" and
  `a.cartesian_tree(by: desc)` is E0310 "no parameter named `by`". The tree form needs a `use`;
  without it E0201 says "not in the stdlib (yet)". The result is parents you wrap yourself.
- **Goal it hurts:** coherence, express.
- **Ideal code:** `let t = a.cartesian_tree(by: desc)`, a `Rooted` over `C` (`dream.cp` line 15).
- **General fix:** one `cartesian_tree` in `std.tree`, in the prelude, keyed like
  `prev_smaller(by:)` (`by: desc` for a max tree), returning the `Rooted`; retire `std.seq`'s.
- **Severity:** low

## `Rooted.from_parents` costs about 0.3 ms per run here
- **Where:** `port.cp` line 16.
- **What felt wrong:** the port reads only `children` and `size`, but `from_parents` builds every
  field (bfs order, `k0`/`k1`, heavy child, chain tops, preorder `tin`/`at`) and the emitted
  `try_from_parents` copies each child list (`for c in kids[queue[i]]: queue.push(c)` becomes
  `std::vector<int> t1 = kids[...]`, as the loop body writes `queue`). Emitted C++ grows from
  11815 to 19218 bytes (`--judge codeforces`), almost all of it the `Rooted` runtime.
- **Goal it hurts:** performance.
- **Ideal code:** the same line, at the old hand-built tree's cost.
- **General fix:** codegen: a loop over `xs[i]` copies only when the body may write `xs`
  (writes to another local don't alias it); and do not build `Rooted` fields no reader uses.
- **Severity:** low (the inputs are n <= 2000)
