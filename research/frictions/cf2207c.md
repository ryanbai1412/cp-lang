# cf2207c friction report

## No Cartesian tree in the stdlib
- **Where:** `cf2207c.cp` lines 13-34.
- **What felt wrong:** A max-Cartesian tree over `a` is built by hand from a stack, with node ids `2 * i + 1` for columns and `2 * i` for gaps, placeholder `Node(0, 0, 0, none, none)` entries, and `c0!`/`c1!` unwraps that the id parity justifies.
- **Goal it hurts:** express, hard to get wrong.
- **Ideal code:** `let t = cartesian_tree(a, by: max)`, then `t.root`, `t.children(i)`, `t.span(i)` over the index domain of `a`.
- **General fix:** add `std.tree.cartesian_tree(xs, by:)` returning a `Rooted` over `xs`'s domain, with `span` per node, in O(n).
- **Area:** tree
- **Severity:** medium
