## Settling a negative delta against the next key is five map calls
- **Where:** `while let cur_val = deltas.get(pos) and cur_val < 0:` / `if let (nxt_k, nxt_v) = deltas.first_gt(pos):` / `if nxt_v == d: deltas.remove(nxt_k) else: deltas[nxt_k] -= d` / `if cur_val + d == 0: deltas.remove(pos) else: deltas[pos] += d`.
- **What felt wrong:** "subtract d, and drop the key at zero" is written twice by hand, each as an `if … remove … else … -=`.
- **Ideal code:** `deltas.add(nxt_k, -d)` / `deltas.add(pos, d)` where a counting map drops a key that reaches 0.
- **General fix:** a std `Counter`-style map (or `Map.add_or_drop`) whose zero entries vanish, so sweep ports that keep only nonzero deltas say each update once. Bag/multiset ports with counts hit the same pair.
- **Goal it hurts:** express, hard-to-get-wrong (forgetting the `remove` leaves a zero key that `first_gt` then finds).
- **Severity:** low.
- **Owner:** stdlib.
