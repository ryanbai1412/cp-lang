# cf2245c — XOR Permutation Order

Both decide by the top bit of `k ^ n` whether a tail of at most three values fixes the prefix-XOR
target, then print every other value descending followed by the reversed tail.

## The port rebuilt the dream's last line by hand
- **Where:** port (before this report)
  ```cp
  var order = [i for i in (0..n).rev if not tail.any(x => x == i)]
  for x in tail.rev: order.push(x)
  print(order)
  ```
  dream `print([i for i in (0..n).rev if not tail.contains(i)] + tail.rev)`.
- **What:** `any(x => x == i)` is `contains(i)` spelled as a predicate (R8), and the push loop is
  list `+` (R3). Both run in 9 ms on `--max` with the same output, so nothing kept the port apart.
- **Status:** fixed in the port with this report; port = dream again.
- **General fix:** a lint for `.any(x => x == e)` suggesting `.contains(e)`.
- **Owner:** idioms; lint-fmt (the lint).
