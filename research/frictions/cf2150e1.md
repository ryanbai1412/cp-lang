## `weight` and `complement` restate the enum's order
- **Where:** `fn weight(c: Copies) -> Int = match c: …` and `fn complement(…) = match weight(total) - weight(left): 0 => … 1 => … _ => …`.
- **What felt wrong:** `Copies` is `None | One | Both`, an ordered count 0..=2; the two matches convert to and from that count by hand.
- **Ideal code:** `domain Copies = 0..=2` (or `Copies.ord` / `Copies.nth(k)` on the enum) and `complement = Copies.nth(total.ord - left.ord)`.
- **General fix:** fieldless enums are already domains; the fix is idiomatic, use `.ord` and `Copies.nth`. I did not change it here: `Copies.One` reads better at the query sites than `1`.
- **Severity:** low. **Owner:** idioms.
