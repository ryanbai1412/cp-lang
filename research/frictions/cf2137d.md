# cf2137d friction report

Port: `corpus/problems/cf2137d/port.cp`. Dream: `corpus/problems/cf2137d/dream.cp`.

No language gaps; the port is simpler than the dream. The dream groups each value's positions, cuts them into `chunks(groups[x], x)`, sorts the runs by first position and numbers them. The port numbers as it scans: a value x opens a fresh label when its previous run is full (`left[x] == 0`), each occurrence takes `label[x]`, and the check `(1..=n).any(x => left[x] > 0)` rejects an unfinished run. That is one \(O(n)\) pass with no lists and no sort, and states the same invariant (each run of x has exactly x members).
