# cf2201a1 — Lost Civilization (easy)

Port = dream: remove from the largest value down on a doubly linked list of survivors kept as
`prv`/`nxt: [0..n]?Int`.

## No std linked list
- **Where:** `var prv: [0..n]?Int = ...`, `var nxt: [0..n]?Int = ...` and the unlink
  `nxt[p] = nx` / `if let q = nx: prv[q] = p`.
- **What:** the survivors are a linked list over the index domain; std has no
  `LinkedList<D>` with `prev`/`next`/`unlink`, so both files keep two tables and unlink by hand.
- **Goal it hurts:** R3 (hand-rolled structure).
- **General fix:** `std.LinkedList<D>` over a domain: `.prev(i)`, `.next(i)`, `.remove(i)`.
- **Severity:** medium (recurs in A2 and other deletion sweeps).
- **Owner:** stdlib.
