# cf2187f2 — Al Fine (counting version)

Same permutation tree as cf2187f1. A non-decreasing node multiplies its
children's counts; a maximal chain of decreasing nodes contributes, besides
the counts of its non-leaf right children, the number of ways to place its
leaf/non-leaf pattern, counted by a prefix-sum DP over the chain read from
the bottom.

## The permutation tree is copied from F1 verbatim

- **Where:** lines 1-50 of `cf2187f2.cp` are byte-identical to
  `cf2187f1.cp` apart from the header and the bound on `n`:
  ```
  fn join(u: Open, t: Open, kind: Kind) -> Open:
      let id = 2 * t.left - 1
      nodes[id] = (kind: kind, l: u.node, r: t.node)
  ```
- **What felt wrong:** the second version of a problem should be a local
  edit of the counting function; instead it duplicates a 30-line structure.
  A personal library would remove the copy, but a contestant would not write
  one mid-contest for a structure the stdlib could own.
- **Goal it hurts:** accumulate, express.
- **Ideal code:**
  ```
  let t = PermTree.new(p)
  fn count(v: t.Node) -> Z = match t.kind(v):
      leaf => 1
      decr => chain(v)
      _ => count(t.left(v)) * count(t.right(v))
  ```
- **General fix:** the stdlib `PermTree` proposed in `cf2187f1.md`.
- **Severity:** high

## In-place prefix sums over a List are lint-blocked; `scan` allocates

- **Where:** the first draft
  ```
  for i in 1..a.len: a[i] += a[i - 1]
  ```
  was rejected by `L0414` (`a[i - 1]` bounds-checked in a nested loop, and
  ports must lint clean); the port now writes
  ```
  ends = scan(ends, (x, y) => x + y)
  ```
- **What felt wrong:** the natural in-place prefix sum has no lint-clean
  spelling on a growing `List`, and the replacement allocates a fresh list per
  leaf of the chain: on the max input the port runs 0.05 s against the
  original's 0.01 s, i.e. the obvious clean code is the slow code.
- **Goal it hurts:** performance, express.
- **Ideal code:**
  ```
  ends.scan_in_place((x, y) => x + y)          // or: for (prev, mut x) in ends.pairs_mut(): x += prev
  ```
- **General fix:** an in-place `scan` (and a neighbour-pair mutable
  iterator) on `List`/arrays, which the lint can then suggest for
  `a[i] += a[i - 1]`.
- **Severity:** medium

## A modulus alias is the only way to avoid repeating `Mod<998_244_353>`

- **Where:**
  ```
  type Z = Mod<998_244_353>
  fn count(v: Int) -> Z:
  var ends: List<Z> = [1]
  ```
- **What felt wrong:** fine once written, but the first draft used
  `List<Mod<998_244_353>>([1])`, which is rejected (`List<T>()` takes no
  arguments) though `List<Z>()` with no arguments works; list literals need a
  type annotation on the binding instead.
- **Goal it hurts:** coherence (two constructor spellings behave differently).
- **Ideal code:** `var ends = List<Z>([1])` or `var ends: List<Z> = [1]`, both accepted.
- **General fix:** let `List<T>(xs)` construct from an iterable, matching
  other collection constructors.
- **Severity:** low

## Chain walk needs a `while` with mutable cursor and repeated `nodes[cur]`

- **Where:**
  ```
  while nodes[cur].kind == Decr:
      let r = nodes[cur].r
      leafs.push(nodes[r].kind == Leaf)
      if nodes[r].kind != Leaf: ways *= count(r)
      cur = nodes[cur].l
  ```
- **What felt wrong:** "walk the left spine while it is decreasing" repeats
  the node lookup four times; with payload enums it is a single
  `while let join(decr, l, r) = nodes[cur]` pattern.
- **Goal it hurts:** express, hard to get wrong.
- **Ideal code:**
  ```
  while let join(kind: decr, l, r) = nodes[cur]:
      leafs.push(nodes[r] == leaf)
      cur = l
  ```
- **General fix:** payload enums with `while let` patterns (`design/spec/11-types.md`), as in `cf2187f1.md`.
- **Severity:** medium

## Measurements

- **Contestant-written tokens:** 727 (port) vs 2,636 (original, whole file
  incl. `modnum` and `PermTree`; 532 for `main` alone) — **0.28x**.

  leaves, so the chain DP is fully quadratic):
  - Port (`g++ -std=c++17 -O2`): **0.05 s**, peak RSS **3,944 KB**
  - Original (`zig c++ -std=c++23 -O2`): **0.01 s**, peak RSS **2,304 KB**
  - Outputs agree; gate: `gate.sh cf2187f2 150` passes (sample + 150 random).
