# cf2261h friction

The port is the dream.

## No heap-numbered tree domain

- **Goal it hurts:** hard-to-get-wrong
- **Severity:** low
- **Area:** stdlib
- **Status:** open
- **Dream:** `proto/ports/ecnerwala/dream/cf2261h.cp:12-20`
- **Actual:** the complete binary tree is spelled in raw heap numbers: `2 * i`, `2 * i + 1`, the leaf test
  `2 * i > size(h)` and the `s[i - 1]` shift between node and string position.
- **General fix:** a complete-binary-tree domain (`domain Node = heap(levels: h)`) with `.left`, `.right`,
  `.is_leaf` and an order-preserving `.ord`, shared with segment-tree and tournament code, so the node space
  is checked like any other domain.
