# cf2062e2 — E2. The Game (Hard Version)

The editorial idea: root at 1 and flatten by preorder so each subtree is a range. A node `v` wins iff the max weight `mx` outside `sub(v)` exceeds `w[v]`, and every node `u` with `w[u] > w[v]` is either inside `sub(v)`, attains `mx` outside `sub(v)`, or is a root-to-leaf path-max ancestor covering all `mx`-nodes outside `sub(v)`.

  ```cp

  var prev_max: [V]?V = none
  ```

- **General fix:** Add `prefix_fold` / `suffix_fold` returning `[Bounds<D>]T` in `stdlib/prefix.cp` (sequences area lane) and `Rooted.top_down` in `stdlib/tree.cp` (trees area lane).

## Key-range views of ordered sets (dream rewrite)
- **Status:** fixed (`SortedSet.range(r)` / `SortedBag.range(r)` O(1) views with O(log n) `.first`/`.last`/`.len`/`.is_empty` and O(log n + k) forward/reverse iteration, open-ended `..b`/`..=b`/`a..`/`..` and `Range<D>` support, `std.bag.SortedSet`, `cpl fix` lint `L0515` codemod migrating `first_ge`/`first_gt`/`last_le`/`last_lt`/`count_range`, old methods removed).
- **Goal it hurts:** express-and-revise.
- **Ideal code:** dream lines 25-30 and 40: `heavier.range(..r.lo)`,
  `heavier.range(r.hi..)`, `heavier.range(t.sub(u))`, each with `.first`,
  `.last` and `.len` in O(log n).
- **Today:** `SortedSet` has `first_ge`/`last_lt`/`count_range(lo, hi)` as
  separate methods taking raw bounds, and ranges can't be open-ended, so the
  "outside a subtree" query is four calls with hand-picked comparisons.
- **General fix:** `SortedSet.range(r)` / `SortedBag.range(r)` returning an
  O(1) view whose `first`, `last`, `len` and iteration cost O(log n) (+ k);
  open-ended range literals `..b` and `a..` over any ordered domain. The
  `first_ge`/`last_lt`/`count_range` family becomes `range(...)` calls and
  goes away with a `cpl fix` codemod. Owners: containers (views), core
  syntax (open ranges).
- **Severity:** medium.
- **Dream:** `proto/ports/ecnerwala/dream/cf2062e2.cp` lines 25-30, 40
