# cf2187e — Doors and Keys

Both keep `dp[k]` for k keys carried, push a front state at a key room and prune states past
`t_inf`.

## `Deque` is 1.7x slower than a front insert into `List`
- **Where:** port `var dp = Deque.of([0])` and `dp.push_front(dp[0])`; dream
  `var dp: List<Int> = [0]` and `dp.insert(0, dp[0])`.
- **What:** the deque is the right structure for a front push (the list insert is O(len)), but
  on the `--max` input it takes 99 ms against the list's 58 ms with the same output: `dp` stays
  short (O(sqrt(n + max a))), so the list's shift is cheap and the deque's indexed reads in the
  inner loop cost more.
- **Goal it hurts:** performance (the obvious structure is the slow one).
- **General fix:** a faster `Deque` index path (contiguous ring buffer with a masked index).
- **Severity:** medium.
- **Owner:** stdlib (containers), perf.
