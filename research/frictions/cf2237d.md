# cf2237d — Mod-3 Substrings

Port = dream: count substrings whose digit-plus-one sum is divisible by 3 with a prefix count
table, minus the alternating suffixes that a run correction removes.

## The adjacent-pair test is written with an index
- **Where:** `cur_len = if i == 0 or c == s[i - 1]: 1 else: cur_len + 1`.
- **What:** "same as the previous character" by index arithmetic; `s.runs()` or a `with_prev`
  view would say it, but the run length is needed inside the same pass as `pref`, so it is an
  equal-cost rewrite at best. Low.
- **Owner:** idioms.

## `cnt: [0..3]Int = [1, 0, 0]`
The `1` is the empty prefix; the header says so. No gap.
