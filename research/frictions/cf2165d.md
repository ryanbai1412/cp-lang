## A two-valued parity is an enum matched to a Bool
- **Where:** `enum Flip: Even | Odd`, `for flip in [Flip.Even, Flip.Odd]:`, and `let is_flipped = match flip: Flip.Even => v % 2 == 0 / Flip.Odd => v % 2 == 1`.
- **What felt wrong:** the enum only names "which parity of values is mirrored"; the five lines of `match` compute `v % 2 == flip.ord`.
- **Ideal code:** `for flip in 0..2:` / `let is_flipped = v % 2 == flip`, or keep `Flip` and write `v % 2 == flip.ord` (fieldless enums have `.ord`).
- **General fix:** none in the language; an idiom choice. Low.
- **Owner:** idioms.

## Positions are mirrored by building lists
- **Where:** `fn reflect(xs: List<Int>) -> List<Int> = [n - 1 - x for x in xs.rev]`, called on every value's positions and on the carried list.
- **What felt wrong:** each call allocates a list only to walk it once in reverse with mirrored keys.
- **Ideal code:** a lazy `xs.rev.map(x => n - 1 - x)` the two-pointer loop can index.
- **Note:** the loop indexes `carried[ptr]`, and a `.rev` view is not indexable (E0305), so the list stays. The total is \(O(n)\) allocation per pass; the port runs the max input inside the limit.
- **Severity:** low. **Owner:** idioms.
