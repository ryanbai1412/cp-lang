## `std.strings.period` only accepts `List<T>`, not `Str` or string slices
- **Area:** `strings` (`plan/STDLIB.md` 4.13)
- **Where:** `proto/ports/ecnerwala/cf1909g.cp` lines 21–22 vs `dream/cf1909g.cp` lines 19–20:
  ```cp
  let block = [t[min_x + i] for i in 0..delta]
  let p = period(block)
  ```
- **What felt wrong:** `std.strings.period<T>(s: List<T>)` does not accept `Str` or a slice of `Str`, forcing an O(delta) copy into a `List<Char>` (on `m = 10_000_000`, `block` allocates up to 10M bytes and copies them just to compute the prefix function).
- **Goal it hurts:** express, performance, coherence.
- **Ideal code (`dream/cf1909g.cp:19-20`):**
  ```cp
  let block = t[min_x..min_x + delta]
  let p = period(block)
  ```
- **General fix:** Accept `Str` (and borrowed slices) in `std.strings.period` and `prefix_function`, avoiding a `List<Char>` copy.
- **Severity:** medium.

## No stepped range syntax (`lo..=hi by step`) in comprehensions / `sum`
- **Area:** core / `sequences` (`plan/STDLIB.md` 4.2)
- **Where:** `proto/ports/ecnerwala/cf1909g.cp` lines 24–28 vs `dream/cf1909g.cp` line 23:
  ```cp
  var ans = 0
  var a = g
  while a <= core_n and a <= delta:
      if delta % a == 0: ans += core_n - a + 1
      a += g
  ```
- **What felt wrong:** Stepping through multiples of `g` requires a manual `while` loop instead of a stepped range inside `sum(...)`.
- **Goal it hurts:** express.
- **Ideal code (`dream/cf1909g.cp:23`):**
  ```cp
  print(sum(core_n - a + 1 for a in g..=min(core_n, delta) by g if delta % a == 0))
  ```
- **General fix:** Support stepped ranges (`a..=b by step` or `.step(g)`) in `for` and generator expressions.
- **Severity:** low.

## No top-level `return` for early exit
- **Area:** core
- **Where:** `proto/ports/ecnerwala/cf1909g.cp` lines 15–17 vs `dream/cf1909g.cp` lines 12–14:
  ```cp
  if max_pre + max_suf <= n:
      print(0)
  else:
      ...
  ```
- **What felt wrong:** Without top-level `return`, the entire main body has to be indented under `else:`.
- **Goal it hurts:** express.
- **Ideal code (`dream/cf1909g.cp:12-14`):**
  ```cp

      print(0)
      return
  ```
- **General fix:** Allow top-level `return` (terminating the current test case / program).
- **Severity:** low.
