# Friction Report: cf2229e

## 1. Domain-indexed `Prefix<D, T>.filling()` and point access `dp[u]`

- **Area:** ranges
- **Goal:** express
- **Severity:** medium
- **Dream:** `proto/ports/ecnerwala/dream/cf2229e.cp:40-47`
- **Port:** `proto/ports/ecnerwala/cf2229e.cp:40-47`

`Prefix<Z>.filling(n)` is 0-indexed over raw `Int`s and has no point read `dp[u]`, so the port converts `V` to `.ord` for `dp.sum(pv.ord + 1..u.ord)`, `dp.set(u.ord, val)`, and `dp.sum(root.ord..root.ord + 1)`. A domain-indexed `Prefix<V, Z>.filling()` with `dp.sum(pv.next!..u)`, `dp.set(u, val)`, and `dp[root]` keeps every index in `V`.

## 2. `max(gen)` traps on empty generator instead of returning `?T`

- **Area:** seq
- **Goal:** express
- **Severity:** low
- **Dream:** `proto/ports/ecnerwala/dream/cf2229e.cp:34-36`
- **Port:** `proto/ports/ecnerwala/cf2229e.cp:34-35`

`max(sub_max[c] for c in t.children(u) if ...)` returns `V` and traps when a vertex has no matching children (leaves), so the port materializes `ch` and checks `if ch.is_empty: none else: some(ch.max())`.
