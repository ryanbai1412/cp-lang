# Friction report: cf2268e

The port and the dream share the per-bit reduction: base `C_n (n - 1)`, minus `sum_d C_d C_(n-d) corr(d)` when the bit's total parity is even. They differ only in how the autocorrelation is paid for.

## The autocorrelation is a hand frequency-domain dot product
- **Where:** `port.cp` lines 25-38: `let size = bit_ceil(2 * n)`, `var w = List.filled(size, Z(0))`, `ntt(mut w)` once, then per bit `ntt(mut a)` and `scale * (a[0] * a[0] * w[0] + sum(a[f] * a[size - f] * w[f] for f in 1..size))`.
- **What felt wrong:** the dream says what is computed, `convolve(a, [a[n - i] for i in 0..=n])` then `sum weight[d] * corr[n - d]`. The port writes the transform length, the padding, the `-f` index and the `1 / size` scale by hand, so one sum is spread over five lines that have to agree.
- **Goal it hurts:** express, hard-to-get-wrong.
- **Ideal code:** the dream's lines 66-71: `var a: [0..=n]Z = 1`, `let corr = convolve(a, a.rev)`, `for d in 1..n: cur -= weight[d] * corr[n - d]`.
- **General fix:** a std `Ntt` plan that keeps a transformed operand (`let wt = ntt.transform(weight)`) and offers `ntt.dot(a, a.rev, wt)` or `autocorrelation(a)`. The port would then cost one transform per bit with no hand indexing. The same applies to any port that convolves many sequences against one fixed kernel. Owner: stdlib.
- **Severity:** low.

## The sign recurrence reloads `a[i - 1]` through memory

- **Where:** `port.cp`, `for i in 1..=n: a[i] = if xs[i].bit(b): -a[i - 1] else: a[i - 1]`.
- **What happened:** the loop emits `a[i] = bit ? neg(a[i - 1]) : a[i - 1]`, so each step reads back the element the step before stored. On `--max` (best of 21 interleaved runs, idle machine) the port is 106.6 ms against orig.cpp's 93.9 ms, 1.135x, at 0.63x RSS. The same emitted C++ with `a[i - 1]` carried in a local runs 94.8 ms, 1.01x. A local accumulator for the `sum`, dropping `check_range(b)`, and `-fpredictive-commoning` each leave it at 1.13x. The tuned `perf.cp` (1.04x) stays until codegen carries the value.
- **Goal it hurts:** performance; the obvious recurrence should be the fast one.
- **General fix:** in a counted loop that stores `a[i]` and reads `a` only at `a[i - k]`, keep the last `k` stored values in locals. Owner: Perf A, with cf2268e's recurrence as the regression test.
- **Severity:** low.
