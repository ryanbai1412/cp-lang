# cf2062e1 — E1. The Game (Easy Version)

The editorial idea: scan nodes in decreasing weight order, maintaining the LCA of all nodes strictly heavier than the current weight. The first node `v` that is not an ancestor of that LCA has a heavier node outside its subtree, while every strictly heavier node contains all nodes heavier than itself in its subtree — so picking `v` forces Daiyousei to make a move after which Cirno has no legal move and wins.

## No `List.first(where:)` / `find(xs, pred)` for list search
- **Where:** `proto/ports/ecnerwala/cf2062e1.cp` lines 21-22:
  ```cp
  for v in by_w[weight]:
      if not t.is_anc(v, l): return v
  ```
- **What felt wrong:** `find` only exists on `Str`, and `stdlib/seq.cp` has no `first(where:)` / `find(xs, pred)` on `List<T>` or iterables, so finding the first matching element requires a 2-line loop.
- **Goal it hurts:** express
- **Ideal code:**
  ```cp
  if let v = bucket.first(where: v => not t.is_anc(v, l)): return v
  ```
- **General fix:** Add `first(xs, pred) -> ?T` (and `any`/`all`) to `stdlib/seq.cp` (or prelude) for all iterables.
- **Dream:** `dream/cf2062e1.cp` line 19.
- **Severity:** medium

## No `group(by:)` bucket builder on domains
- **Where:** `proto/ports/ecnerwala/cf2062e1.cp` lines 14-15:
  ```cp
  var by_w: [W]List<V> = []
  for v in V: by_w[w[v]].push(v)
  ```
- **What felt wrong:** Grouping a domain `V` into buckets indexed by another domain `W` is a 2-line imperative loop that recurs in nearly every weight-sweep tree problem.
- **Goal it hurts:** express
- **Ideal code:**
  ```cp
  let by_w = V.group(by: v => w[v])
  ```
- **General fix:** Provide a `group<D, K>(by: D -> K) -> [K]List<D>` (or `Map<K, List<D>>` for non-domain keys) helper in `stdlib/seq.cp`.
- **Dream:** `dream/cf2062e1.cp` line 13.
- **Severity:** low

## `Rooted.new` uses 1.23x runtime and 1.76x memory vs C++ on $n = 4 \cdot 10^5$
- **Where:** `proto/ports/ecnerwala/cf2062e1.cp` line 12:
  ```cp
  let t = Rooted.new(Graph.undirected(edges), V.first)
  ```
- **What felt wrong:** On $n = 4 \cdot 10^5$, the port runs in 0.16 s (113 MB RSS) vs 0.13 s (64 MB RSS) for C++ (1.23x runtime, 1.76x RSS). `Rooted.new` unconditionally stores 64-bit `Int` arrays (`tin`, `sz`, `dep`, `par`, `head`, `at`, `far`) and builds weighted-depth tables even for unweighted trees, doubling memory traffic.
- **Goal it hurts:** performance
- **Ideal code:**
  ```cp
  let t = Rooted(Graph.undirected(read<[V.count - 1](V, V)>()), root: V.first)
  ```
- **General fix:** Store `Int32` for domain-sized indices (`tin`, `sz`, `dep`, `par`) inside `Rooted` (domains are already bounded by `i32::MAX`) and omit `far` when unweighted.
- **Dream:** `dream/cf2062e1.cp` line 11.
- **Severity:** medium

## `print(win() ?? 0)` cannot coalesce `?V` with `Int` `0`
- **Where:** `proto/ports/ecnerwala/cf2062e1.cp` line 27:
  ```cp
  if let v = win(): print(v) else: print(0)
  ```
- **What felt wrong:** `win()` returns `?V`, and `0` is an `Int`, so `win() ?? 0` does not typecheck even for printing a 1-based vertex or `0` for "none".
- **Goal it hurts:** express
- **Ideal code:**
  ```cp
  print(win() ?? 0)
  ```
- **General fix:** Allow `print(opt, none: 0)` (symmetric with `read(none: 0)`) so optional domain values print with a sentinel without an `if let ... else:` branch.
- **Dream:** `dream/cf2062e1.cp` line 24.
- **Severity:** low
