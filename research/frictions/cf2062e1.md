# cf2062e1 — E1. The Game (Easy Version)

The editorial idea: scan nodes in decreasing weight order, maintaining `heavier_lca`, the LCA of all nodes strictly heavier than the current weight. The first node `v` that is not an ancestor of `heavier_lca` has a strictly heavier node outside its subtree, while every heavier node contains all nodes heavier than itself — so picking `v` wins.

(`first(by_w[weight], v => not t.is_anc(v, l))` now works on `main` and replaced the manual search loop.)

## No `V.group(by:)` domain bucketing helper (owned by sequences area lane)
- **Status:** fixed: `std.seq.buckets(w)` maps `[V]W` to `[W]List<V>` in O(V.count + W.count) (`2ed3cd3d`). The port now writes `let by_w = buckets(w)` (`gate.sh cf2062e1 50` passes).
- **Where:** `proto/ports/ecnerwala/cf2062e1.cp` lines 14-15:
  ```cp
  var by_w: [W]List<V> = []
  for v in V: by_w[w[v]].push(v)
  ```
- **What felt wrong:** Grouping a domain into buckets indexed by another domain takes a manual mutable array + loop.
- **Goal it hurts:** express
- **Ideal code:**
  ```cp
  let by_w = V.group(by: v => w[v])
  ```
- **General fix:** Add `group(by:)` on domains/sequences in `stdlib/seq.cp` (sequences area lane).
- **Dream:** `dream/cf2062e1.cp` line 8.
- **Severity:** low

## `Rooted.new` uses 64-bit index tables (1.23x runtime, 1.76x RSS vs C++) (owned by trees area lane)
- **Where:** `proto/ports/ecnerwala/cf2062e1.cp` line 12:
  ```cp
  let t = Rooted.new(Graph.undirected(edges), V.first)
  ```
- **What felt wrong:** On `n = 400_000`, `Rooted.new` runs in 0.16 s and 113 MB RSS vs C++ 0.13 s and 64 MB RSS because internal Euler-tour / HLD tables store 64-bit `Int` indices.
- **Goal it hurts:** performance
- **Ideal code:** Same `Rooted(...)` call, backed by 32-bit internal index arrays.
- **General fix:** Narrow internal index tables in `stdlib/tree.cp` to 32-bit when `V` fits in `i32` (trees area lane).
- **Dream:** `dream/cf2062e1.cp` line 6.
- **Severity:** medium
