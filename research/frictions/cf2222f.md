# cf2222f — F. Building Tree

The editorial idea: divide-and-conquer on weight range `[lo, hi]` with rollback connectivity. On entry to `solve(lo, hi)`, `conn` holds all edges with weight outside `[lo, hi]` and carries one representative colored vertex per component (`DsuOf<V, ?V>`). Adding all edges in one half merges colored components at the other half's minimum weight (`lo` or `mid + 1`), building the minimum spanning forest over colored vertices in $O(m \log m)$.

## No scoped rollback (`with conn.checkpoint():` / `defer`) for rollback DSU (owned by containers area lane / core `defer`)
- **Where:** `proto/ports/ecnerwala/cf2222f.cp` lines 45-53:
  ```cp
  let snap = conn.mark()
  add_range(mid + 1, hi, lo)
  solve(lo, mid)
  conn.undo_to(snap)

  if links == need: return
  add_range(lo, mid, mid + 1)
  solve(mid + 1, hi)
  conn.undo_to(snap)
  ```
- **What felt wrong:** `std.dsu.DsuOf<V, ?V>` and nominal `Mark` (containers area lane) already eliminated the manual payload stack and swappable raw `Int` marks. The remaining gap is that rollback is manual `mark()` / `undo_to(snap)` rather than lexically scoped, so an early `return` between `mark()` and `undo_to(snap)` would silently leak state into sibling branches.
- **Goal it hurts:** hard-to-get-wrong, express
- **Ideal code:**
  ```cp
  with conn.checkpoint():
      add_range(mid + 1..=hi, lo)
      solve(lo, mid)
  ```
- **General fix:** Add a core `defer` statement (`decisions.md` 26.8) rather than a block-taking fn or lazy param:
  1. **Block-taking fn** (`conn.scoped(|| ...)`): collides with the single-lender rule — `scoped(mut self, ...)` holds a mutable lend of `conn`, so the body cannot call `conn.unite`.
  2. **Lazy parameter** (`conn.scoped(body)`): same aliasing conflict, since `body` still runs inside `scoped` while `self` is lent.
  3. **Core `defer`** (`let s = conn.mark(); defer conn.undo_to(s)`): lends `conn` only at `mark()` and at scope exit, so the body mutates `conn` freely and early `return`/`break` always undoes.
  4. **Coherence:** one general core mechanism covers rollback DSU, DFS enter/exit, and temporary state without stdlib privilege.
  5. **Recommendation:** core `defer` (with optional sugar `with conn.checkpoint():` desugaring to `let _s = conn.mark(); defer conn.undo_to(_s)`).
- **Dream:** `dream/cf2222f.cp` lines 34-40.
- **Severity:** medium

## No `edges.filter(...).group(by:)` for one-line bucketing
- **Where:** `proto/ports/ecnerwala/cf2222f.cp` lines 19-22:
  ```cp
  var by_w: [0..=m]List<(u: V, v: V)> = []
  for e in edges:
      if e.u != e.v:
          by_w[e.w].push((u: e.u, v: e.v))
  ```
- **What felt wrong:** Bucketing non-loop edges by weight takes 4 lines of imperative initialization boilerplate instead of `filter` + `group(by:)`.
- **Goal it hurts:** express
- **Ideal code:**
  ```cp
  let by_w = edges.filter(e => e.u != e.v).group(by: e => e.w)
  ```
- **General fix:** Add `group(by:)` to `stdlib/seq.cp`.
- **Dream:** `dream/cf2222f.cp` line 16.
- **Severity:** low
