# cf2187c — Jerry and Tom

Both build the `nxt` pointer tree and merge depth tables small-into-large through
`merge_by_depth`; the port adds one line.

## The port frees each merged list by hand
- **Where:** port `by_depth[i] = []` after the merge; the dream leaves the list.
- **What:** the line keeps peak memory at the live lists only. It is also faster here
  (17 ms vs the dream's 34 ms on `--max`). The language gives no way to say "move this list into
  the merge" so it is dropped after; the port writes the drop as an assignment.
- **Goal it hurts:** express, performance.
- **General fix:** a consuming parameter (`from: own List<Bucket>`) so the caller's slot is
  emptied by the move.
- **Severity:** low.
- **Owner:** compiler (ownership).

## The sink self-loop
`var nxt: [V]V = [V] i => i.next ?? i` gives `n` a self-loop that `assert p != i` then rules
out. A domain fact `nxt[i] > i` would prove the swap disjoint; today the assert is needed for
the aliasing check (E0601 without it).
