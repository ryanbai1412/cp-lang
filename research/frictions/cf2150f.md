## Algorithm

Build a spanning tree `T` via `Dsu<V>`, root it with `Rooted(tree, V.first)`, and find its diameter `(len, u, v) = T.diameter()`. Operation 1 (`k = 3`) adds all missing edges between pairs of tree neighbors of each vertex, turning `G` into a superset of `T^2`. Operation 2 (`k = ceil(diam / 2) + 1`) connects every remaining non-adjacent pair `(i, j)` using a simple path of length `path_len = ceil(diam / 2)` in `T^2`: either skipping vertices along `T.path(i, j)` if `dist(i, j) >= path_len`, or detouring toward the further diameter endpoint (`d.u` or `d.v`) and zigzagging out and back along the shared suffix.

## Frictions

### 1. No domain half-range / unordered-pair iteration
- **Where:** `cf2150f.cp`, lines 34–35 and 40 (`dream/cf2150f.cp`, lines 36 and 40):
  ```cp
  for i in V:
      for j in V if j > i and not adj[i, j]: num_ops += 1
  ```
- **What felt wrong:** Iterating unordered pairs `i < j` over `domain V = 1..=n` appears twice (counting `num_ops` and emitting op-2 paths) and scans the full `V x V` grid with `if j > i`, because domains lack `V.after(i)` or `V.pairs`. Counting matching pairs also needs a 3-line accumulator loop instead of `count(...)`.
- **Goal it hurts:** express, performance.
- **Ideal code (`dream/cf2150f.cp`, lines 36 and 40):**
  ```cp
  print(count(for i in V, j in V.after(i) where not adj[i, j]))
  ...
  for j in V.after(i) where not adj[i, j]:
  ```
- **General fix:** Support open-start domain subranges (`V.after(i)`) and `count(for ...)` generator reductions.
- **Severity:** low.

### 2. No open-ended list suffix slicing
- **Where:** `cf2150f.cp`, line 63 (`dream/cf2150f.cp`, line 59):
  ```cp
  let extras = [pif[k] for k in pif.len - keep..pif.len]
  ```
- **What felt wrong:** Copying the last `keep` elements of a list requires an explicit index comprehension `[pif[k] for k in pif.len - keep..pif.len]` instead of a slice `pif[pif.len - keep..]`.
- **Goal it hurts:** express.
- **Ideal code (`dream/cf2150f.cp`, line 59):**
  ```cp
  let extras = pif[pif.len - keep..]
  ```
- **General fix:** Support open-ended list slices `xs[start..]` returning a sub-list/slice.
- **Severity:** low.
