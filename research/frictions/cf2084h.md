## `Str.runs()` is missing (`stdlib/seq.cp` `runs` only accepts `[D]T`, not `Str`)
- **Where:** `cf2084h.cp`, lines 23–26 (`dream/cf2084h.cp`, line 8):
  ```cp
  var blocks = [1]
  for i in 1..n:
      if s[i] == s[i - 1]: blocks[blocks.len - 1] += 1
      else: blocks.push(1)
  ```
- **What felt wrong:** Splitting a string `s: Str` into maximal runs still takes a 4-line manual loop because `Str` has no `.runs()` method and `std.seq.runs` only accepts `[D]T`.
- **Goal it hurts:** express, hard-to-get-wrong
- **Ideal code (`dream/cf2084h.cp`, line 8):**
  ```cp
  let blocks = read<Str>().runs().map(r => r.len)
  ```
- **General fix:** Add `Str.runs()` (or make `runs()` generic over any `Seq` including `Str`, zero-allocating on `Str`).
- **Severity:** medium

## No `List.pop_if(pred)` for monotone-stack pop loops
- **Where:** `cf2084h.cp`, lines 13–15 (`dream/cf2084h.cp`, lines 20–21):
  ```cp
  while let cur = steps.last, cur.top <= top:
      steps.pop()
      if let b = steps.last: hidden -= M(b.top - cur.top) * b.v
  ```
- **What felt wrong:** Monotone-stack pop loops repeat peek + predicate + `steps.pop()`, rather than binding the popped element directly in `while let s = steps.pop_if(s => s.top <= top):`.
- **Goal it hurts:** express
- **Ideal code (`dream/cf2084h.cp`, lines 20–21):**
  ```cp
  while let s = steps.pop_if(s => s.top <= top):
      if let b = steps.last: hidden -= M(b.top - s.top) * b.v
  ```
- **General fix:** Add `pop_if(mut self, pred: T -> Bool) -> ?T` on `List<T>`.
- **Severity:** low

## No `let st = mut stairs[k % 2]` mutable element reference or `blocks.drop_last().enumerate()`
- **Where:** `cf2084h.cp`, lines 40–45 (`dream/cf2084h.cp`, lines 30–35):
  ```cp
  for k in 0..blocks.len - 1:
      let z = k % 2
      stairs[z].lift += 1
      if k >= 1: stairs[z].push(blocks[k], dp)
      let floor = if z == 0: blocks[0] else: 1
      dp = stairs[z].visible() + M(floor + stairs[z].lift - 1)
  ```
- **What felt wrong:** Re-indexing `stairs[z]` three times in the loop body (and writing `0..blocks.len - 1` + `blocks[k]` instead of `blocks.drop_last().enumerate()`) adds noise around the recurrence.
- **Goal it hurts:** express
- **Ideal code (`dream/cf2084h.cp`, lines 30–35):**
  ```cp
  for (k, len) in blocks.drop_last().enumerate():
      let st = mut stairs[k % 2]
      st.lift += 1
      if k >= 1: st.push(len, dp)
      let floor = if k % 2 == 0: blocks.first else: 1
      dp = st.visible() + M(floor + st.lift - 1)
  ```
- **General fix:** Support local mutable projection bindings (`let st = mut a[i]`) and `drop_last()` / `.enumerate()` on `List<T>`.
- **Severity:** low

## Mixing `Int` expressions with `Mod<P>` requires explicit `M(...)` wrapping on every term
- **Where:** `cf2084h.cp`, lines 15, 16, 20, 36, 45, 46 (`dream/cf2084h.cp`, lines 9, 21, 22, 26, 35, 36):
  ```cp

  ...
  print(dp * M(blocks.last!))
  ```
- **What felt wrong:** Multiplying or adding a `Mod<P>` by an `Int` expression requires `M(...)` around every integer expression.
- **Goal it hurts:** express

  ```cp

  ```
- **General fix:** Allow `Mod<P> * Int`, `Int * Mod<P>`, and `Mod<P> += Int` when one side is already `Mod<P>`.
- **Severity:** low
