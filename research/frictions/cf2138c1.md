## Bounded subset sum was hand-rolled
- **Where:** the old `is_good`, `var ff: [0..=n]Int` counting each layer size, then `var dp = Bitset<S>…`, `var p = 1` / `while rem > 0:` / `dp |= dp.shifted(take * w)` (binary splitting by hand). The dream has the same loop.
- **Ideal code:** `S(k) in Bitset<S>.subset_sums([freq[i] for i in 0..l] + List.filled(deep, 1))`: the first `l` layers are whole items, every vertex below is its own item.
- **Fix:** the port now uses std `Bitset.subset_sums`, which groups equal weights with the same binary carries. 30 stress cases agree; 0.008 s at max against 0.007 s before. Done in this commit.
- **Goal it hurts:** express (a std algorithm written out by hand).
- **Owner:** idioms (done).

## Parents read into a shifted table

- **What felt wrong:** the usual "parents of 2..n" input needs a three-line copy into the `[V]?V` shape `from_parents` takes.
- **Ideal code:** `let t = Rooted.from_parents(read_parents(V, root: V(1)))`, or `from_parents` accepting a `[2..=n]V`.
- **General fix:** a `Rooted` constructor from the parents of every non-root vertex, keyed by a sub-domain. Every "p₂ … pₙ" tree input uses it.
