## Multi-variable declaration requires a tuple initializer rather than broadcast scalar
- **Where:** `cf2069c.cp`, line 5 (`dream/cf2069c.cp`, line 7):
  ```cp
  var ones, open, ans: Z = (0, 0, 0)
  ```
- **What felt wrong:** Declaring three zero-initialized counters of the same type requires repeating `0` three times as `(0, 0, 0)` instead of broadcasting a single scalar `= 0`.
- **Goal it hurts:** express.
- **Ideal code (`dream/cf2069c.cp`, line 7):**

- **General fix:** Allow a single scalar initializer to broadcast across a multi-variable declaration `var a, b, c: T = x`.
