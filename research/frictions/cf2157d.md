## A sorted copy of a dead input
- **Where:** dream `let raw = read()` then `let a = raw.sorted()`; the port reads `var raw` and sorts it in place.
- **What felt wrong:** the dream's form is the one a contestant writes (the input stays immutable), but `raw` is never used again, so `.sorted()` pays for a second array of n values.
- **Ideal code:** the dream, at the port's cost.
- **General fix:** codegen moving a dead local into `sorted()` (sort the moved buffer instead of copying), which every "read, then sort" port would get for free.
- **Severity:** low.
- **Owner:** perf.

The answer, pairing the i-th smallest with the i-th largest clamped to `[l, r]`, is the same.
