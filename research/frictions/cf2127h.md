# cf2127h friction report

## Undirected edge map with endpoint-oriented payloads (`UndirectedMap<V, Edge>`)
- **Where:** `dream/cf2127h.cp` lines 55, 61, 80–81, 88.
- **What felt wrong:** Storing per-edge DP tables on an undirected graph forces manual `canon(u, v)` key normalization plus `flip(e)` on every read and write (`pop_edge` / `add_edge`).
- **Goal it hurts:** express, hard-to-get-wrong (forgetting `flip` on one side silently corrupts edge tables).
- **Ideal code:** `edges: UndirectedMap<V, Edge>` where `edges[u, v]` and `edges.remove(u, v)` automatically orient the table to `(u, v)`.
- **General fix:** an unordered-pair key or symmetric-edge map wrapper in `std.graph` / `std.containers`.
- **Area:** graphs
- **Severity:** medium

## 2D row/column slice views (`a[au]`, `b.col(bv)`) for capped max-plus convolution
- **Where:** `dream/cf2127h.cp` lines 38, 43, 46.
- **What felt wrong:** `[Deg, Deg]Int` does not support taking a 1D row view `a[au]` or column view `b.col(bv)` to pass into a shared 1D `max_plus_cap` helper, forcing `parallel`, `series`, and `absorb_leaf` to inline three separate 4-deep loop nests in `cf2127h.cp`.
- **Goal it hurts:** express.
- **Ideal code:** `max_plus_cap(max_plus_cap(a[au], mid), b.col(bv))[Deg(2)]`.
- **General fix:** 1D row/column views on 2D domain-indexed arrays.
- **Area:** core
- **Severity:** low
