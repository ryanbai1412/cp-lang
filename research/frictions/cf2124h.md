# Friction report: ecnerwala/cf2124h

## 1. No triangular (`i <= j`) table domain

- **Severity**: medium
- **Goal**: express
- **Area**: containers
- **Dream**: `proto/ports/ecnerwala/dream/cf2124h.cp` lines 16, 23, 34, 38
- **Details**: The DP stores one `0..=2 * n` value for every pair `0 <= i <= j < n`, which needs `n * (n + 1) / 2` entries (half of a square `n x n` table, keeping peak memory at ~225 MB for `n = 15_000`). Today the port defines a manual linearizer `fn tidx(i: Int, j: Int) -> Int = j * (j + 1) / 2 + i` over a flat `[0..n * (n + 1) / 2]0..=2 * n` array. A triangular table or dependent domain (`[i <= j]`) would eliminate `tidx` and verify `i <= j` at the index site.
