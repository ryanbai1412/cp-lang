## `List.sort(by:)` allocates three temporary vectors and uses indirect `std::stable_sort`
- **Area:** `sequences` (`plan/STDLIB.md` 4.2) / codegen
- **Where:** `proto/ports/ecnerwala/cf1284e.cp` line 16 (`dirs.sort(by: d => ByAngle(d))`), emitted as `cpl::sort_by`.
- **What felt wrong:** Calling `dirs.sort(by: d => ByAngle(d))` inside an `O(n)` outer loop (`n = 2500`) allocates `keys`, `order`, and `sorted` vectors on every call and runs `std::stable_sort` through index indirection `keys[a] < keys[b]`, plus `ByAngle`'s `Ord` calls `angle_less` with `I128` `cross128` on every comparison. On `n = 2500`, the port takes `691.5 ms` vs `383.4 ms` for the C++ original (`1.80x`, though still well under the 3s TL).
- **Goal it hurts:** performance.
- **Ideal code (`dream/cf1284e.cp:16`):**
  ```cp
  dirs.sort(by: d => ByAngle(d))
  ```
- **General fix:** For pure, cheap key projections (like wrapping a `Pt` in `ByAngle(d)`), specialize `sort(by:)` to sort in-place without allocating `keys`/`order`/`sorted` (or provide `sort_unstable(by:)` / comparator-based in-place `sort` with zero auxiliary allocations).
- **Severity:** medium.

## No exact integer `choose(n, k)` for small `k` in `std.math`
- **Area:** `number theory/combinatorics` (`plan/STDLIB.md` 4.3)
- **Where:** `proto/ports/ecnerwala/cf1284e.cp` lines 11–12 (`choose3`, `total_quads`).
- **What felt wrong:** Small exact binomials like `C(k, 3)` and `C(n - 1, 4)` still have to be written out as `k * (k - 1) * (k - 2) / 6` (and `choose2` is a recurring helper across many ports).
- **Goal it hurts:** express.
- **Ideal code:** `choose(k, 3)` / `choose(n - 1, 4)` from `std.math`.
- **General fix:** Add exact small-`k` `choose(n: Int, k: Int) -> Int` (or `choose2`/`choose3`) in `std.math`.
- **Severity:** low.
