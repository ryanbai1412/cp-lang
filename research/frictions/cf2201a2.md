# cf2201a2 — Lost Civilization (hard)

Same sweep as A1: visit indices by value descending, and when the left survivor is exactly one
less, unlink `i` and subtract the `(p + 1) * (n - i)` subarrays it no longer starts.

## The port had drifted to sentinels and a packed sort key
- **Status:** fixed in the port with this report.
- **Where:** port before:
  ```cp
  var prv: [0..n]0..=n = [0..n] i => if i > 0: i - 1 else: n  // n: none
  for key in sorted([(10 ** 9 - a[i]) << 19 | i for i in 0..n]):  // a desc, then i (n < 2^19)
      let i = key % (1 << 19)
  ```
  dream: `[0..n]?Int` neighbours and `(0..n).sorted(by: i => (-a[i], i))`.
- **What:** `n` as "no neighbour" and a hand-packed key with a `2^19` assumption, each
  explained by a comment (R5, R8). The dream's form runs at the same speed (27 ms vs 28 ms on
  `--max`, same output), so the port now is the dream; `corpus.py verify` is clean.
- **Goal it hurts:** hard-to-get-wrong.
- **Severity:** medium (the packed key breaks silently if `n` grows past `2^19`).
- **Owner:** idioms.
