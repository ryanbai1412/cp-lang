# cf2211e — Interactive Tree Cuts

Port = dream: read the tree bottom-up interactively; per vertex combine children's
`gcd`-reduced `good` by `lcm`, and cut (cost + 1) when it collapses to 1.

## Gaps

None. The reads are bounded (`a <= 1e18`, `k <= n`, children in `V`) and the per-vertex
combine is two std calls. `lcm` stays within `1e18` because each factor divides `a`.
