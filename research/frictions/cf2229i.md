# cf2229i friction

## No max-plus correlation (the transpose of convolution)

- **Goal it hurts:** express
- **Severity:** medium
- **Area:** stdlib
- **Status:** partly fixed: the convolution half is `convolve(a, b, over: Semiring(max, +))`
  (port line 38); the transpose is still missing.
- **Dream:** `corpus/problems/cf2229i/dream.cp` (`max_plus_correlate(f, b)`)
- **Actual:** `corpus/problems/cf2229i/port.cp` `split` hand-writes
  `res[i] = max_j f[i + j] + b[j]` over `?Int` (none for impossible). Reversing `b` into
  `convolve` gives the same values but costs |f| |b| instead of (|f| - |b| + 1) |b|, which is
  O(n^3) on a path here.
- **Repro:** `convolve([0, 3, 5], [0, 2], over: Semiring(max, +), correlate: true)` ->
  error[E0310] "`convolve` has no parameter named `correlate`".
- **General fix:** a correlation form of `convolve` (`out[i] = add over j of mul(a[i + j], b[j])`,
  length |a| - |b| + 1) for every semiring, taking `List<?T>` so "impossible" needs no sentinel;
  the rerooting staple for knapsacks.

## Spec says a shapeless non-(+, *) `convolve` is an error; std runs it in O(nm)

- **Goal it hurts:** coherence
- **Severity:** low
- **Area:** stdlib / spec
- **Where:** `spec/lib/ops-ranges.md` §13 ("Without one it is an error, not a hidden
  O(n^2)") vs `std/ntt.cp` `semiring_convolve`, which takes `shape: None` and loops.
  The port now states `shape: Curved.Neither` (port line 38), which checks and runs today;
  std still accepts the shapeless call the spec rejects.
- **General fix:** one answer: a `shape: Neither` (the `std/README.md` `Shape` already
  lists it) that states the O(nm) loop, and an error only without any shape.

## `convolve(over:)` emits its dead `+`/bitwise/NTT branches and is slower than the loop

- **Goal it hurts:** submission, performance
- **Severity:** low
- **Area:** codegen, stdlib
- **Where:** port line 38. Emitted C++ 24,029 -> 29,925 bytes (`m3_convolve` 2,513,
  `m3_semiring_convolve` 1,883 per `cpl build --size`): the `same(over.add, +)` and
  `same(on, ^)` tests are on zero-size op values, known at compile time, yet every branch
  is emitted. `semiring_convolve` also folds into a `List<?T>` and unwraps it, where the
  hand loop started from 0: path n = 4000, 0.12 s vs 0.11 s for the hand `join`.
- **General fix:** fold comparisons of zero-size operation values at monomorphization and
  drop the dead branches (helps every `on:`/`over:` std fn); seed the accumulator from
  `a[0] * b[j]`/`a[i] * b[0]` instead of `?T`.
