# cf2222a — Hundred

Port = dream up to spelling: is any value equal to 100.

## Gaps

None. The dream writes `if any(x == 100 for x in a): "Yes" else: "No"`, the port
`yes(a.any(x => x == 100), answers: ("Yes", "No"))`; both are current spellings and the port's
is the one the corpus uses for yes/no output.
