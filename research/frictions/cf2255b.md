# cf2255b — Run Arrangements

Both split the binary string into runs and multiply, per digit present, `C(total - 1, blocks - 1)`.

## `Str of "01"` can't carry its length
- **Where:** port `let s: Str of "01" = read()` then `assert s.len == n`; dream
  `let s: [0..n]Char = read()`.
- **What:** the port checks the alphabet in the type but not the length, so it asserts it; the
  dream checks the length but not the alphabet (`Bit(c - '0')` traps on a bad character instead).
  Neither states both facts in the read.
- **Goal it hurts:** R5, R12.
- **General fix:** a length-bounded alphabet read, `Str<n> of "01"` or `[0..n]Char of "01"`.
- **Severity:** low.
- **Owner:** stdlib (io), compiler (refined `Str`).
