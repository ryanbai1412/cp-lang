# cf2180h1 — Bug Is Feature (easy)

The dream reads the series into a typed table of five `1..=10 ** 18` fields and XORs
`prefix_xor` over it with one `fold(..., ^)`; the port XORs into a `var ans` while reading.

## The port folds by hand where the dream folds
- **Where:** port lines `var ans = 0` / `repeat n:` / `ans ^= ...`; dream
  `let ans = fold(prefix_xor(r - c + 1, c - b) ^ prefix_xor(l - c, c - b) for (_, b, c, l, r) in qs, ^)`.
- **What:** the dream form checks and runs today (32 ms vs the port's 47 ms on `--max`, same
  output), so this is an owed rewrite, not a gap. The port also adds `assert c - b == b - a`,
  which the statement guarantees; the dream drops `a` with `_`.
- **Goal it hurts:** express (R2: an accumulator threaded by hand).
- **General fix:** none needed in the language; the port should take the dream's table and fold.
- **Severity:** low.
- **Owner:** idioms.

## `Coord` names the bound once in the port only
The port's `type Coord = 1..=10 ** 18` writes the bound once (R4); the dream repeats it five
times. The better spelling is the port's; a refreshed dream should take it.
