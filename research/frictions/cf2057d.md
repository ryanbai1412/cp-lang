## `SegTree` `Monoid.op` lowers via `std::function` and `?Span` uses 64-bit fields + `std::optional`
- **Area:** `range structures` (`plan/STDLIB.md` 4.10) / codegen
- **Where:** `proto/ports/ecnerwala/cf2057d.cp` line 26 (`SegTree<Pos, ?Span>(Monoid(id: none, op: combine), ...)`).
- **What felt wrong:** On `n = 200_000, q = 200_000`, the CP Lang binary takes `109.4 ms` vs `54.3 ms` for C++ (`2.01x`). `Monoid.op` erases `combine` through `std::function`, preventing inlining on every tree-node pull, and `Span`'s five `Int` fields wrapped in `std::optional<Span>` take 48 bytes per node (vs 20 bytes in C++ `int`s).
- **Goal it hurts:** performance.
- **Ideal code (`dream/cf2057d.cp:24`):**
  ```cp
  var tree = SegTree<Pos, ?Span>(Monoid(id: none, op: Span.combine), [Pos] i => Span.leaf(i, a[i]))
  ```
- **General fix:** Devirtualize/monomorphize `Monoid.op` in codegen instead of lowering through `std::function`, and support a non-empty `Semigroup` segment tree (or niche-packed `?Span`) so full-domain trees do not pay for `std::optional` per node.
- **Severity:** medium.

## No variadic `max` or static associated functions on structs (`Span.leaf`, `Span.combine`)
- **Area:** core / `sequences` (`plan/STDLIB.md` 4.2)
- **Where:** `proto/ports/ecnerwala/cf2057d.cp` lines 13–24 vs `dream/cf2057d.cp` lines 10–22:
  ```cp
  max(max(a.best, b.best), max(a.lo_l + b.hi_r, a.hi_l + b.lo_r))
  ```
- **What felt wrong:** `max` only takes two arguments, forcing nested `max(max(...), max(...))`, and `leaf`/`combine` must be free functions rather than `Span.leaf`/`Span.combine` associated functions on `struct Span`.
- **Goal it hurts:** express.
- **Ideal code (`dream/cf2057d.cp:10-22`):**
  ```cp
  struct Span(best: Int, lo_l: Int, hi_l: Int, lo_r: Int, hi_r: Int):
      fn leaf(p: Pos, x: Int) -> Span = ...
      fn combine(a: ?Span, b: ?Span) -> ?Span:
          ...
          max(a.best, b.best, a.lo_l + b.hi_r, a.hi_l + b.lo_r)
  ```
- **General fix:** Allow variadic `max`/`min` (3+ args) and static associated functions inside `struct` bodies.
- **Severity:** low.
