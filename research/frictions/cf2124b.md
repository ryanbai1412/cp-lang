# cf2124b friction report

Port: `corpus/problems/cf2124b/port.cp`. Dream: `corpus/problems/cf2124b/dream.cp`.

## Reading only a prefix of an array needs a skip loop
- **Where:** port lines 14-16, `let (a0, a1): (0..=2 * n, 0..=2 * n) = read()` then `for _ in 2..n: let ai: 0..=2 * n = read()  // the rest never matters`.
- **Dream:** `let a: [0..n]0..=2 * n = read()` and `a[0] + min(a[0], a[1])`.
- **What felt wrong:** the dream form costs a stored array of n values that are never read (peak 4.3 MB against the port's 3.0 MB and the original's 3.0 MB, which is why b966a496a moved to the skip loop). The loop reads into a dead `ai` only to consume input, and its bound has to be restated.
- **Goal it hurts:** express, performance.
- **Ideal code:** `let (a0, a1, ..): … = read(n)` or `read().skip(n - 2)`: say "the rest is input, not data".
- **General fix:** a std way to consume and discard k values (`skip_read(k)`, or a rest pattern in tuple reads) that the reader can make a token skip. Any port whose answer depends on a prefix or on aggregates only would use it.
- **Severity:** low.
- **Owner:** stdlib.
