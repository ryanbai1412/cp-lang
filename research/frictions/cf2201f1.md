# cf2201f1 — Transpose Hash (easy)

Port = dream: a row-length histogram per side, its multiset hashed incrementally as
`splitmix64` of a packed `(length, rank)` key, answering whether the two histograms are
transposes.

## The key is packed by hand
- **Where:** `let key = match s: Left => (U64(f) << 32) | U64(g)  Right => (U64(g) << 32) | U64(f)`
  then `h[s] += splitmix64(key)`.
- **What:** the pair is packed into one `U64` because `splitmix64` takes a word. std derives
  `Hash` for tuples (`std/derive.cp`), so `(f, g).hash()` would say "hash this pair" without the
  32-bit layout assumption; the sum-of-hashes multiset trick still needs a per-element hash,
  which is what `.hash()` gives.
- **Goal it hurts:** hard-to-get-wrong (a silent collision past `2^32`), express.
- **General fix:** none in the language; owed rewrite to `(f, g).hash()` once it is measured
  against `splitmix64` on `--max`.
- **Severity:** low.
- **Owner:** idioms.

## The dream lags the port
The dream types `row`/`freq` as `Int` and prints `if ...: "YES" else: "NO"`; the port bounds
the counts by `q` and uses `yes(...)`. The port is the better spelling; the dream should take it.
