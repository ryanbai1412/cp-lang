# Friction: `cf2157c`

## Per-write `cpl::at` bounds checks and signed `cpl::emod` in tight $O(qn)$ loop (1.8x slowdown)

- **Severity:** medium
- **Goal it hurts:** performance
- **Measured:** `419.23 ms` vs `237.46 ms` (`1.77x`) on `gen size=25000` (`research/scoreboard.json`).
- **Cause (codegen pattern):** `for i in l - 1..r:` runs `cpl::at(in_min, i)` / `cpl::at(in_mex, i)` bounds checks on every inner iteration, and `cnt % k` emits signed Euclidean `cpl::emod` even when `cnt >= 0`.
- **Fix:** hoist loop-invariant slice bounds checks (`0 <= l - 1 <= r <= n`) before the loop and emit plain `%` when both operands are non-negative.
