## The dream reads `n >= 2`, the port `n >= 1`
- **Where:** dream `let n: 2..=200_000`, port `let n: 1..=2e5`.
- **What:** the two disagree on the lower bound; `n = 1` (no edges) is legal in the port's read
  and gives `0.0`. One of them is wrong about the statement, and no statement file is in the
  package to settle it. Neither traps on the package's cases.
- **Goal it hurts:** R5 (a fact stated two ways).
- **General fix:** packages carry the statement's limits block, so a reviewer can check reads.
- **Severity:** low.
- **Owner:** idioms.

## `s[u.ord]` indexes a string by vertex
`let s: Str = read()` then `s[u.ord]`: the string's index space is `V` shifted by one. Reading
`s` as `[V]Char` would remove the `.ord` and say it once; that needs a `Str` read into a table
indexed by a domain, which `read()` doesn't do for `Str` today. Owner: stdlib (io).
