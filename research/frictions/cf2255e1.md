# cf2255e1 friction

The original is byte-identical to cf2255e2's, so this port is now the
cf2255e2 port (`DualSegTree`, `MaxSub`, sign-indexed paths) and the dream is
its dream. The gaps are the ones in `research/frictions/cf2255e2.md`.

## Enum-indexed tables and inline match arms

- **Goal it hurts:** express
- **Severity:** low
- **Area:** core
- **Status:** open
- **Dream:** `proto/ports/ecnerwala/dream/cf2255e1.cp:7,11,45`
  (`enum Sign` with values, `[Sign]Path`, `match kind: 1 => ...; 2 => ...`)
- **Actual:** `proto/ports/ecnerwala/cf2255e1.cp:9-17`
  writes `Sign` as `-1..=1` and the table as three named fields picked by
  `path`; the operation match takes four lines.
- **General fix:** arrays indexed by an enum (one fact per variant) and a
  one-line match arm separator.
