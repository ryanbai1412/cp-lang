# cf2237g

- **Source:** Codeforces 2237G (`proto/ports/ecnerwala/cf2237g_orig.cpp`)
- **Port:** `proto/ports/ecnerwala/cf2237g.cp`
- **Dream:** `proto/ports/ecnerwala/dream/cf2237g.cp`
- **Status:** Ported. `gate.sh` has no interactor for this two-run problem (0 cases), so it was checked with a two-run harness over 60 random seeds. The harness compares the first run's output byte for byte with the C++ and plays judge for the second run.

## A field-less `@tags` enum cannot be read

- **Goal it hurts:** coherence
- **Severity:** medium
- **Area:** io
- **Status:** open
- **Dream:** `proto/ports/ecnerwala/dream/cf2237g.cp:16-17,29-32,37`
- **Actual:** `proto/ports/ecnerwala/cf2237g.cp:59-62,70`
- **General fix:** decision 15.9 says an enum with `@tags(...)` has a written form, and enums with fields read as their tag (`noi15p2`). `@tags("first", "second") enum Run: First, Second` still gets E0501 "`read()` has no input format for a `Run`", so the port compares a `Str` to `"first"`. A field-less tagged enum should read as its tag, so the run dispatch can be a `match`.

## No bit-stream view of a list of fixed-width words

- **Goal it hurts:** express
- **Severity:** medium
- **Area:** stdlib
- **Status:** open
- **Dream:** `proto/ports/ecnerwala/dream/cf2237g.cp:34,41`
- **Actual:** `proto/ports/ecnerwala/cf2237g.cp:17-20`
- **General fix:** `xs.bits(w)`, a lazy little-endian stream of the low `w` bits of each element, plus `chunks(w)` on a bit stream that packs each chunk back into an `Int`, zero-padding the last one. Today the port hand-writes `recut` and materialises a `List<Bool>` of every bit.

## No layer-by-layer generation or `take_while` on sequences

- **Goal it hurts:** express
- **Severity:** low
- **Area:** stdlib
- **Status:** open
- **Dream:** `proto/ports/ecnerwala/dream/cf2237g.cp:21-25`
- **Actual:** `proto/ports/ecnerwala/cf2237g.cp:26-41`
- **General fix:** `take_while(pred)` on sequences, so a sorted prefix can be cut without a loop and `break`, and a breadth-first `layers(next)` / `flatten` that lists every value reachable from a seed in BFS order. The port has `grow` with a `break` loop and a `while` loop that concatenates layers.

## Inverting a list into a position table is a loop

- **Goal it hurts:** express
- **Severity:** low
- **Area:** stdlib
- **Status:** open
- **Dream:** `proto/ports/ecnerwala/dream/cf2237g.cp:26-27`
- **Actual:** `proto/ports/ecnerwala/cf2237g.cp:39-47`
- **General fix:** `xs.positions()` returning a `[0..=xs.max]?Int` (or `Map`) from value to index, the list analogue of `inverse()` on permutation tables. Also missing: integer `ilog(base)` (dream line 27, port `top_power` at line 43).

## Interactive queries have no call form

- **Goal it hurts:** express
- **Severity:** low
- **Area:** io
- **Status:** open
- **Dream:** `proto/ports/ecnerwala/dream/cf2237g.cp:39-40`
- **Actual:** `proto/ports/ecnerwala/cf2237g.cp:50-57`
- **General fix:** a `query(...)` that prints and reads its reply, with the judge's `-1` abort handled by the interactive runtime rather than by every caller. Then the decode is one `prod` per symbol, with no `?Int` threaded out of a loop.

## The derived encoding emits 54% more C++

- **Goal it hurts:** performance
- **Severity:** low
- **Measured:** the emitted C++ grows from 12,861 B to 19,840 B. Runtime is unchanged (21 ms vs 22 ms median over 20 runs; the C++ is 9 ms, mostly the sieve). The growth comes from the `?Int` table over `0..=V` and the comprehensions in `recut` and the layers, which replace hand loops over `Int` lists. The table is the honest type for "not a symbol". It is rebaselined.
