## A static method is not a function value

- **Goal it hurts:** express
- **Severity:** low
- **Area:** core
- **Status:** open
- **Dream:** `proto/ports/ecnerwala/dream/cf2201d.cp:27`
- **Actual:** `Monoid(SegNode.empty(), SegNode.join)` fails ("`join` needs the argument `x`"), so the
  combine is wrapped as `(x, y) => SegNode.join(x, y)`.
- **General fix:** a bare path to a function or static method (`SegNode.join`, `max`) is a value of its
  function type wherever a closure is expected.
