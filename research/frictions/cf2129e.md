# cf2129e friction

## No bucketed counting multiset

- **Goal it hurts:** express
- **Severity:** medium
- **Area:** stdlib
- **Status:** open
- **Dream:** `proto/ports/ecnerwala/dream/cf2129e.cp:23-24,34-36`
  (`BucketCount(0..bit_ceil(n + 1))`, `values.add(x, by)`, `values.kth(k)`)
- **Actual:** `proto/ports/ecnerwala/cf2129e.cp:25-48` defines a local
  `Bucketed` struct: a count per value plus a count per sqrt block, with the
  two-level k-th walk.
- **General fix:** a stdlib counting multiset over a value range with O(1)
  `add(x, by)` and O(sqrt) `kth`/`rank`, the companion every Mo's-algorithm
  port needs (a Fenwick tree's O(log) update is too slow under Mo's
  O((n + q) sqrt n) steps).

## Building a domain from a computed list and indexing it by position

- **Goal it hurts:** hard to get wrong
- **Severity:** low
- **Area:** core
- **Status:** open
- **Dream:** `proto/ports/ecnerwala/dream/cf2129e.cp:17-18,28,39`
  (`let (domain Arc, arcs) = [...].indexed()`, `arcs[p]`,
  `first_arc[x.l.l]`)
- **Actual:** `proto/ports/ecnerwala/cf2129e.cp:18-20,23,62` declares
  `domain Arc = 0..arcs.len` after the list, indexes it with `p.to_idx`, and
  converts `Int` prefix sums back with `Arc.bounds.nth(...)`.
- **General fix:** the `.indexed()` binding the exemplars already sketch (a
  list together with the domain of its positions), so arrays computed at
  runtime get a domain without an `Int` round trip.
