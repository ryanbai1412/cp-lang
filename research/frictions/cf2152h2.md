# cf2152h2 friction

The port keeps the original's algorithm (Kruskal heaviest first, a slope-trick
function per component as a meldable heap of breakpoints) and now derives it in
the header; the raise step is one named fn with a guarded `while let`.

## No meldable heap in `std.heap`

- **Goal it hurts:** express
- **Severity:** high
- **Area:** stdlib
- **Status:** open
- **Dream:** `proto/ports/ecnerwala/dream/cf2152h2.cp:20,28-31,35-36,38`
  (`MeldHeap<T>`, `.top`, `.pop()`, `.push_all(...)`, `.meld(other.take())`,
  `.drain()`)
- **Actual:** `proto/ports/ecnerwala/cf2152h2.cp:16-35,57-75` defines `Breaks`,
  a skew-heap arena (parallel lists, `?Int` roots), and threads roots through
  `single`/`meld`/`rest` by hand.
- **General fix:** a `MeldHeap<T>` (skew or leftist, O(log n) amortized `meld`)
  with the same surface as `MinHeap` plus `meld`. Slope trick on trees,
  small-to-large-free merging, and mergeable priority queues all need it;
  `MinHeap` small-to-large is O(n log^2 n).

## Small gaps

- **Goal it hurts:** express
- **Severity:** low
- **Area:** stdlib
- **Status:** open

- `dream:18`: the vertex boundary as a per-vertex sum; written as the edge loop
  (`cf2152h2.cp:41-44`) because the sum over incident edges is O(n m). Not a
  gap: the loop is the right cost. Kept in the dream only as notation.
- `dream:33` `(pos - val - d).divmod(slope - 1)`: no integer `divmod`
  (`std.poly.div_mod` is polynomial); the port writes `/` and `%` on the
  same operands (`cf2152h2.cp:59`). General fix: `divmod` in `std.math`.
- `dream:39` `breaks.count_below(l)` on a sorted list: the port writes
  `breaks.first_ge(l) ?? breaks.len` (`cf2152h2.cp:74`). General fix: a
  rank (number of elements below) on sorted sequences, matching
  `SortedBag.rank`.

## Measurement

Max case (n = q = 250,000, random tree), `g++ -O2`: old 0.19-0.23 s / 55 MB,
new 0.19-0.21 s / 40 MB, same output. Emitted C++ 17,698 -> 20,481 bytes
(the bounded input types and the arena struct); rebaselined.
