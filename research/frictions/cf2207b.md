# cf2207b — Mascot Naming

Both keep the window of the `min(m, remaining + 1)` smallest counters and add each step to the
earliest minimum (`vals.argmin()!`), dropping the front at each `a[idx]`.

## The dream read a narrower box than the statement
- **Status:** fixed in the dream with this report.
- **Where:** dream `let (n, m, l): (1..=2_000, 1..=2_000, 1..=2_000) = read()`; the port has
  `let (n, m): (1..=2e5, 1..=2e5)` and `let l: n..=2e5 / m`.
- **What:** the statement bounds `m * l`, not each value by 2000; the dream rejected valid
  inputs such as `m = 1, l = 2e5` (the `--max` case, `m * l = 2e5`, happened to fit). The dream
  now reads the port's two lines.
- **Goal it hurts:** R5.
- **Severity:** medium.
- **Owner:** idioms.

## The window is a `List` with front removal
- **Where:** `vals.remove(0)` and `vals.argmin()!` each step.
- **What:** both are O(window), so a step costs O(min(m, n)); with `m * l <= 2e5` that is the
  intended O(l * min(m, n)), 4 ms on `--max`. No faster structure is needed.
- **Severity:** none; recorded so a reader doesn't reach for a heap.
