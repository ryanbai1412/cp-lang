# cf2147h — Maxflow GCD Coloring

## `Bitset<D>` lacks direct iteration, `.find(pred)`, `.without(v)`, and direct `print(c)`
- **Where:** `cf2147h.cp`, lines 15, 37–39, 44–48 (`dream/cf2147h.cp`, lines 14, 21, 26–27):
  ```cp
  print([v for v in c.each()])
  ...
  for u in s.each():
      odd[u] ^= s
      odd[u].remove(u)
  ...
  let v = first(v for v in alive.each() if (odd[v] & alive).len % 2 == 1) ?? return Bitset<V>.new()
  var rest = alive
  rest.remove(v)
  ```
- **What felt wrong:** `Bitset<D>` still requires `.each()` in `for` loops and generators (`E0302: a for can't walk over a Bitset<V>`), cannot be printed directly (`print(c)`), has no `.find(pred)`, and has no non-mutating `.without(v)` (forcing a mutable copy `var rest = alive; rest.remove(v)` and a second statement `odd[u].remove(u)`). (`all - side`, `V.after(i)`, and `first(...)` now work directly.)
- **Goal it hurts:** coherence, express.
- **Ideal code (`dream/cf2147h.cp`, lines 14, 21, 26–27):**
  ```cp
  print(c)
  ...
  for u in s: odd[u] ^= s.without(u)
  ...
  let v = alive.find(v => (odd[v] & alive).len % 2 == 1) ?? return Bitset.empty
  let rest = alive.without(v)
  ```
- **General fix:** Implement `Seq` + `Print` on `Bitset<D>`, add `.find(pred)`, `.without(x)`, and `V.all` for a domain's full bitset. Helps every graph/DP problem using `Bitset<D>`.
- **Severity:** medium.

## No `gomory_hu(edges)` in `std.flow`
- **Where:** `cf2147h.cp`, lines 13–21 (`dream/cf2147h.cp`, line 16):
  ```cp
  var fg = FlowGraph<V>()
  for e in edges: fg.add_both(e.u, e.v, e.w)
  var par: [V]V = V.first
  var g = 0
  for i in V if i != V.first:
      fg.reset()
      g = gcd(g, fg.max_flow(i, par[i]))
      let cut = fg.min_cut(i)
      for j in V if j > i and par[j] == par[i] and cut[j]: par[j] = i
  ```
- **What felt wrong:** Gusfield's 9-line Gomory-Hu loop is textbook boilerplate that contestants copy from KACTL (`gomoryHu`); `FlowGraph.reset()` made it fast, but expressing "gcd of the Gomory-Hu tree's weights" still requires hand-writing the parent-reassignment loop.
- **Goal it hurts:** express.
- **Ideal code (`dream/cf2147h.cp`, line 16):**
  ```cp
  if gcd(gomory_hu(edges).map(e => e.w)) != 1: return answer([V.all])
  ```
- **General fix:** Add `gomory_hu` to `std.flow` returning the cut-equivalent tree edges `(u: V, v: V, w: Int)`, and `gcd(seq)` reduction on sequences of `Int`.
- **Severity:** low.

## No `adjacency(edges, into: Bitset)` builder
- **Where:** `cf2147h.cp`, lines 27–30 (`dream/cf2147h.cp`, line 18):
  ```cp
  var odd: [V]Bitset<V> = [V] _ => Bitset<V>.new()
  for e in edges if e.w % 2 == 1:
      odd[e.u].toggle(e.v)
      odd[e.v].toggle(e.u)
  ```
- **What felt wrong:** Building an undirected bitset adjacency table from an edge list repeats `[V] _ => Bitset<V>.new()` and symmetric insertion.
- **Goal it hurts:** express.
- **Ideal code (`dream/cf2147h.cp`, line 18):**
  ```cp
  var odd = adjacency(edges.filter(e => e.w % 2 == 1), into: Bitset)
  ```
- **General fix:** Support `adjacency(edges, into: Bitset)` (or symmetric `Bitset` graph builder) in `std.graph`.
- **Severity:** low.
