# cf2147h — Maxflow GCD Coloring

## `Bitset<D>` lacks direct iteration, `.first(pred)` / `.find(pred)`, `.without(v)`, and direct `print(c)`
- **Where:** `cf2147h.cp`, lines 17, 34–43 (`dream/cf2147h.cp`, lines 14, 21, 26–27):
  ```cp
  print([v for v in c.each()])
  ...
  let v = first(
      v for v in alive.each() if (odd[v] & alive).len % 2 == 1
  ) ?? return Bitset<V>.new()
  var rest = alive
  rest.remove(v)
  let nbr = odd[v] & rest
  var next_odd = odd
  for u in nbr.each():
      next_odd[u] ^= nbr
      next_odd[u].remove(u)
  ```
- **What felt wrong:** `Bitset<D>` still requires `.each()` in `for` loops and generators (`E0302: a for can't walk over a Bitset<V>`), cannot be printed directly (`print(c)`), has no method-form `.first(v => ...)` (per §49), and has no non-mutating `.without(v)` (forcing a mutable copy `var rest = alive; rest.remove(v)` and a second statement `next_odd[u].remove(u)`). (`all - side`, `V.after(i)`, and `first(...)` work directly.)
- **Goal it hurts:** coherence, express.
- **Ideal code (`dream/cf2147h.cp`, lines 14, 21, 26–27):**
  ```cp
  print(c)
  ...
  let v = alive.first(v => (odd[v] & alive).len % 2 == 1) ?? return Bitset.empty
  let rest = alive.without(v)
  let nbr = odd[v] & rest
  var next_odd = odd
  for u in nbr: next_odd[u] ^= nbr.without(u)
  ```
- **General fix:** Implement `Seq` + `Print` on `Bitset<D>`, add `.first(pred)` / `.without(x)` (containers lane), and `V.all` for a domain's full bitset. Helps every graph/DP problem using `Bitset<D>`.
- **Severity:** medium.

  ```cp
  var g = 0
  for e in gomory_hu(edges): g = gcd(g, e.w)
  ```
- **What felt wrong:** `std.flow.gomory_hu` now replaces the hand-rolled Gusfield loop, leaving only the 2-line `gcd` fold over the tree's weights.
- **Goal it hurts:** express.
- **Ideal code (`dream/cf2147h.cp`, line 16):**
  ```cp
  if gcd(gomory_hu(edges).map(e => e.w)) != 1: return answer([V.all])
  ```
- **General fix:** Add `gcd(seq)` reduction on sequences of `Int` (math lane).
- **Severity:** low.

## No `adjacency(edges, into: Bitset)` builder
- **Where:** `cf2147h.cp`, lines 26–29 (`dream/cf2147h.cp`, line 18):
  ```cp
  var odd = [V] _ => Bitset<V>.new()
  for e in edges if e.w % 2 == 1:
      odd[e.u].toggle(e.v)
      odd[e.v].toggle(e.u)
  ```
- **What felt wrong:** Building an undirected bitset adjacency table from an edge list repeats `[V] _ => Bitset<V>.new()` and symmetric insertion.
- **Goal it hurts:** express.
- **Ideal code (`dream/cf2147h.cp`, line 18):**
  ```cp
  var odd = adjacency(edges.filter(e => e.w % 2 == 1), into: Bitset)
  ```
- **General fix:** Support `adjacency(edges, into: Bitset)` (or symmetric `Bitset` graph builder) in `std.graph`.
- **Severity:** low.
