# Friction: `cf2261g`

## Un-niched `Row<std::optional<ll>, 2>` and per-node temporary `std::vector` in `Trie` (3.5x slowdown)

- **Status:** closed (`?Int` in `cpl::Row<cpl::OptInt, 2>` is niched to 8 B, and `emit_row_init` in `crates/cpl-codegen/src/expr.rs` now constructs fixed-size `cpl::Row<T, K>` fields directly on the stack for array comprehensions/literals/fills without a per-node temporary `std::vector`; matched `bench/strings/trie` dropped from `43.8 ms` / `1.33x` to `35.4 ms` vs `33.8 ms` C++17 / `1.05x`).
- **Severity:** high
- **Goal it hurts:** performance
- **Measured:** `357.41 ms` vs `100.79 ms` (`3.55x`) on `gen size=25000` (`research/scoreboard.json`).
- **Cause (layout + codegen):** `struct Trie(cnt: Int, kid: [0..2]?Int)` emits `cpl::Row<std::optional<ll>, 2>` (32 B for two children instead of two niched 4-byte `int32_t` indices), and `[0..2] b => ...` inside `chain()` allocates a temporary `std::vector<std::optional<ll>>` on every trie node (`25 * n` heap allocations).
- **Fix:** niche `?Int` / `?Pos` inside fixed-size `Row` fields and emit fixed-size array comprehensions directly on the stack without a heap `std::vector`.

## No binary trie with counts and destructive merge

- **Goal it hurts:** express, hard to get wrong
- **Severity:** medium
- **Area:** stdlib
- **Status:** open
- **Dream:** `proto/ports/ecnerwala/dream/cf2261g.cp:8, 12, 21-23`
- **Actual:** `proto/ports/ecnerwala/cf2261g.cp:11, 17-40`
- **General fix:** a fixed-width `BitTrie<W>` in the stdlib (counts per node, `of(x)`, `absorb` that merges another trie in amortized O(total nodes), and `walk(x)` yielding `(bit, subtree)` along a path). `std.strings.Trie` is alphabet-indexed with `-1` children and no merge, so the port keeps its own arena of `Node(cnt, kid: [Bool]?Int)`, a bottom-up `chain` builder and a recursive `merge`.

## Merging equal neighbours of a list has no stdlib form

- **Goal it hurts:** express
- **Severity:** low
- **Area:** stdlib
- **Status:** open
- **Dream:** `proto/ports/ecnerwala/dream/cf2261g.cp:22`
- **Actual:** `proto/ports/ecnerwala/cf2261g.cp:47-52`
- **General fix:** `merge_runs(by: key, combine)` on sequences (the run-length analogue of `group(by:)`), which folds each run of equal keys with `combine`. The port rebuilds `kept` with a `kept.last` check.

## A `[Bool]` table's comprehension index is an `Int`

- **Goal it hurts:** coherence
- **Severity:** low
- **Area:** types
- **Status:** open
- **Dream:** `proto/ports/ecnerwala/dream/cf2261g.cp:8`
- **Actual:** `proto/ports/ecnerwala/cf2261g.cp:29-31`
- **General fix:** `[Bool] b => ...` should bind `b: Bool`, as `kid[x.bit(z)]` already indexes by `Bool`. Today `[Bool] b => if b == x.bit(z): ...` fails with E0302 (`Int` vs `Bool`), so the port fills with `none` and assigns the one child.
