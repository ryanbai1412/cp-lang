# Friction: `cf2124f2`

## 64-bit `Mod<P>` 2D DP table and `cpl::last` optional wrapping in inner loop (1.6x slowdown)
- **Where:** `cf2124f2.cp` lines 22, 29, 44–47 (`dream/cf2124f2.cp` lines 23, 41, 45–48).
- **What felt wrong:** `wrap_diff: [0..n, 0..n + 2]Z` stores 8-byte `Mod<998_244_353>` elements (2x footprint) with bounds-checked `.ck(x0, i)` indexing, and `bads[d].last ?? n` constructs a `std::optional<ll>` on every access.
- **Goal it hurts:** performance
- **General fix:** Narrow `Mod<P>` to `uint32_t` when $P < 2^{31}$ and inline `.last ?? default` without materializing `std::optional`.
- **Severity:** medium

## No online sweep difference array (`Diff1` is offline-only)
- **Where:** `cf2124f2.cp` lines 26–39 (`dream/cf2124f2.cp` lines 25–41):
  ```cp
  var over_cur: Z = 0
  var over_diff: [0..n + 2]Z = 0
  fn add_over(lo: Int, hi: Int, v: Z):
      if lo <= hi:
          over_diff[lo] += v
          over_diff[hi + 1] -= v
  ```
- **What felt wrong:** `std.prefix.Diff1` only supports offline materialization via `finish()`, not online left-to-right sweep (`add(lo..=hi, v)` while advancing `i` and reading the running value).
- **Goal it hurts:** express
- **Ideal code (`dream/cf2124f2.cp` lines 25–41):** A `SweepAdd` / `Diff1.advance(i)` that accumulates range adds online, plus a flat 2D variant without nested vector overhead.
- **General fix:** Add an online `step`/`advance` cursor (or `SweepDiff`) to `std.prefix`.
- **Severity:** low

## No `List.pop_while(pred)` for stack/tail cleanup
- **Where:** `cf2124f2.cp` line 56 (`dream/cf2124f2.cp` line 59):
  ```cp
  while let last = bads[d].last, last < i: bads[d].pop()
  ```
- **What felt wrong:** Draining expired entries from the back of a sorted list repeats peek + predicate + `pop()`.
- **Goal it hurts:** express
- **Ideal code (`dream/cf2124f2.cp` line 59):**
  ```cp
  bads[d].pop_while(p => p.ord < i)
  ```
- **General fix:** Add `pop_while(mut self, pred: T -> Bool)` alongside `pop_if` on `List<T>`.
- **Severity:** low
