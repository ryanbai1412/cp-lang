# Friction: `cf2124f2`

## 64-bit `Mod<P>` 2D DP table and `cpl::last` optional wrapping in inner loop (1.6x slowdown)
- **Where:** `cf2124f2.cp` lines 27, 35, 51–54 (`dream/cf2124f2.cp` lines 29, 35, 39–42).
- **What felt wrong:** `wrap_diff: [0..n, 0..n + 2]Z` stores 8-byte `Mod<998_244_353>` elements (2x footprint) with bounds-checked `.ck(x0, i)` indexing, and `next_bad(d) ?? Cut.last` constructs a `std::optional` on every access.
- **Goal it hurts:** performance
- **General fix:** Narrow `Mod<P>` to `uint32_t` when $P < 2^{31}$ and inline `.last ?? default` without materializing `std::optional`.
- **Severity:** medium

## No online sweep difference array (`Diff1` is offline-only)
- **Where:** `cf2124f2.cp` lines 32–45 (`dream/cf2124f2.cp` lines 34–35, 38, 41, 46, 51):
  ```cp
  var over_cur: Z = 0
  var over_diff: [0..n + 2]Z = 0
  fn add_over(lo: Int, hi: Int, v: Z):
      if lo <= hi:
          over_diff[lo] += v
          over_diff[hi + 1] -= v
  ```
- **What felt wrong:** `std.prefix.Diff1` only supports offline materialization via `finish()`, not online left-to-right sweep (`add(lo..=hi, v)` while advancing `c` and reading the running value).
- **Goal it hurts:** express
- **Ideal code (`dream/cf2124f2.cp` lines 34–35, 38, 41, 46, 51):** `SweepAdd<Cut, Z>` in `std.prefix` with `.add(lo..=hi, v)` and `.advance(c) -> Z`, plus a flat 2D variant without nested vector overhead.
- **General fix:** Add an online `SweepAdd<D, T>` cursor to `std.prefix`.
- **Severity:** low

## No `List.pop_while(pred)` for stack/tail cleanup
- **Where:** `cf2124f2.cp` line 61 (`dream/cf2124f2.cp` line 49):
  ```cp
  while let last = bads[d].last, last < c: bads[d].pop()
  ```
- **What felt wrong:** Draining expired entries from the back of a sorted list repeats peek + predicate + `pop()`.
- **Goal it hurts:** express
- **Ideal code (`dream/cf2124f2.cp` line 49):**
  ```cp
  bads[d].pop_while(p => p < c)
  ```
- **General fix:** Add `pop_while(mut self, pred: T -> Bool)` alongside `pop_if` on `List<T>`.
- **Severity:** low
