# Friction: `cf2124f2`

## 64-bit `Mod<P>` 2D DP table and `cpl::last` optional wrapping in inner loop (1.6x slowdown)

- **Severity:** medium
- **Goal it hurts:** performance
- **Measured:** `32.74 ms` vs `20.55 ms` (`1.59x`) on `gen size=1000` (`research/scoreboard.json`).
- **Cause (layout + codegen):** `dp_x_lazy: [0..n, 0..n + 2]Z` stores 8-byte `Mod<998_244_353>` elements (2x footprint) with bounds-checked `.ck(x0, i)` indexing, and `bads[...].last ?? n` constructs a `std::optional<ll>` on every access.
- **Fix:** narrow `Mod<P>` to `uint32_t` and inline `.last ?? default` without materializing `std::optional`.
