# cf2115d friction report

## `XorBasis` can't label its pivots
- **Where:** `cf2115d.cp` lines 21-30.
- **What felt wrong:** The game needs to know which player inserted each pivot of a reduced XOR basis. `std.matrix.XorBasis.add` returns only `Bool` and keeps its pivots private, so the port hand-writes the basis plus a parallel `maximize: [0..60]Bool`.
- **Goal it hurts:** express.
- **Ideal code:** `var basis = XorBasis<Bool>()`, `basis.add(d, label: c[i] == '1')`, `for (v, maximize) in basis.pivots: …`.
- **General fix:** let `XorBasis` carry a label per pivot (or return the new pivot's bit from `add`) and expose its pivots in reduced form.
- **Area:** math
- **Severity:** low
