# cf2180h2 — Bug Is Feature (conditional)

Same shape as `cf2180h1`: the dream folds `prefix_xor` over a typed table, the port XORs
while reading. The odd/even closed forms are identical.

## Hand fold and a five-times-repeated bound
- **Where:** port `repeat n:` with `let (a, b, c, l, r): (1..=10 ** 18, ... five times) = read()`
  and `ans ^= ...`; dream `fold(... for (_, b, c, l, r) in qs, ^)`.
- **What:** the dream's fold checks and runs at the same speed (30 ms vs 27 ms, same output),
  so the hand accumulator is an owed rewrite. Both files write `1..=10 ** 18` five times;
  `cf2180h1`'s `type Coord` says it once.
- **Goal it hurts:** express, R4.
- **General fix:** none in the language; a tuple-of-one-type read (`(Coord; 5)`-style) would
  remove the repetition, low priority.
- **Severity:** low.
- **Owner:** idioms.

## Constants
The port names `EVEN_BITS_FROM_2` and `ODD_D_GRUNDY` as `const`; the dream binds them with
`let` in lower case. `const` is the right spelling for a fixed table; no gap.
