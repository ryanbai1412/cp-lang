# cf2062g — G. Permutation Factory

The editorial idea: view `p` as points `(i, p[i])` and `q` as points `(j, q[j])`. Every swap of cost `min(|i - j|, |p[i] - p[j]|)` reduces total Manhattan distance to any target matching by at most 2, so half the minimum Manhattan matching cost is a lower bound. It is always achieved in two stages: first sort positions `i -> mate[i]` by swaps reducing position distance, then sort values `p[i] -> q[mate[i]]` by swaps reducing value distance.

(`first(cyc, x => perm[x] < x)!` and `first(cyc.rev, x => x < r) ?? i` now work on `main` and eliminated the `?D` flag-and-break loop.)

## No `min_weight_matching` and no `a - b -> Int` distance on domain elements (owned by flow / domains area lane)
- **Where:** `proto/ports/ecnerwala/cf2062g.cp` lines 31-33:
  ```cp
  let (_, mate) = max_weight_matching<I, I>(
      (i, j) => -(abs(i.ord - j.ord) + abs(p[i].ord - q[j].ord))
  )
  ```
- **What felt wrong:** Finding a minimum-weight matching requires negating weights in `max_weight_matching`, and computing the distance between two elements of the same domain `I` requires `.ord` on every operand.
- **Goal it hurts:** express, hard-to-get-wrong
- **Ideal code:**
  ```cp
  let (_, mate) = min_weight_matching<I, I>((i, j) => abs(i - j) + abs(p[i] - q[j]))
  ```
- **General fix:** Add `min_weight_matching` to `stdlib/flow.cp` (graphs/flow area lane) and allow `a - b -> Int` on elements of the same ordered domain `D` (domains area lane).
- **Dream:** `dream/cf2062g.cp` line 32.
- **Severity:** medium

## Passing a fresh working copy to a mutating helper requires a throwaway `var` and `mut` (owned by core)
- **Where:** `proto/ports/ecnerwala/cf2062g.cp` lines 35-36, 44:
  ```cp
  var pos_perm: [I]I = [I] i => mate[i]
  var ops = sort_perm(mut pos_perm)
  ```
- **What felt wrong:** `sort_perm` only mutates its own working copy, yet the caller must bind a throwaway `var pos_perm` and pass `mut pos_perm`.
- **Goal it hurts:** express
- **Ideal code:**
  ```cp
  var ops = sort_perm([I] i => mate[i])
  ```
- **General fix:** Support by-value mutable parameters (`mut perm: [D]D` or owned copy) when the caller passes an rvalue (core).
- **Dream:** `dream/cf2062g.cp` lines 34, 42.
- **Severity:** low
