# cf2062g — G. Permutation Factory

The editorial idea: view `p` as 2D points `(i, p[i])` and `q` as `(j, q[j])`. Any swap of cost $\min(|i - j|, |p_i - p_j|)$ decreases the total Manhattan distance to any target matching by at most $2$, so half the minimum Manhattan matching cost is a lower bound. Finding a minimum-weight matching `mate: [I]I` via Hungarian (`max_weight_matching` with negated weights) achieves this bound in two identical permutation-sorting stages: first sort positions `i -> mate[i]`, then sort values `p[i] -> q[mate[i]]` while tracking each value's current position.

## No `List.first(where:)` / `last(where:)` forces a manual flag-and-break search loop
- **Where:** `proto/ports/ecnerwala/cf2062g.cp` lines 21-28:
  ```cp
  var l = i
  var r: ?D = none
  for x in cyc:
      if perm[x] < x:
          r = x
          break
      l = x
  let r_val = r!
  ```
- **What felt wrong:** Finding the first cycle element `r` with `perm[r] < r` and the element `l` immediately preceding it in sorted order requires a mutable `?D` variable and a `break` loop instead of `first(where:)`.
- **Goal it hurts:** express
- **Ideal code:**
  ```cp
  let r = cyc.first(where: x => perm[x] < x)!
  let l = cyc.last(where: x => x < r) ?? i
  ```
- **General fix:** Add `first(xs, pred) -> ?T` and `last(xs, pred) -> ?T` to `stdlib/seq.cp` (or prelude).
- **Dream:** `dream/cf2062g.cp` lines 20-21.
- **Severity:** medium

## No `min_weight_matching` counterpart and no `abs(i - j)` distance on domain elements
- **Where:** `proto/ports/ecnerwala/cf2062g.cp` line 39:
  ```cp
  let (_, mate) = max_weight_matching<I, I>((i, j) => -(abs(i.ord - j.ord) + abs(p[i].ord - q[j].ord)))
  ```
- **What felt wrong:** Two small frictions in one line: (1) `stdlib/flow.cp` only exports `max_weight_matching`, requiring negation for min-cost assignment, and (2) subtracting two elements of the same domain `I` requires `.ord` on every element (`i.ord - j.ord`) instead of `abs(i - j)`.
- **Goal it hurts:** express
- **Ideal code:**
  ```cp
  let (_, mate) = min_weight_matching<I, I>((i, j) => abs(i - j) + abs(p[i] - q[j]))
  ```
- **General fix:** Export `min_weight_matching` alongside `max_weight_matching` in `stdlib/flow.cp`, and support `a - b -> Int` for two elements of the same domain `D`.
- **Dream:** `dream/cf2062g.cp` line 31.
- **Severity:** low

## Mutating a parameter requires an explicit `var` temporary and `mut` at the call site
- **Where:** `proto/ports/ecnerwala/cf2062g.cp` lines 41-42, 49:
  ```cp
  var pos_perm: [I]I = [I] i => mate[i]
  var ops = sort_perm(mut pos_perm)
  ```
- **What felt wrong:** Because `sort_perm` only mutates its own working copy, we cannot pass `[I] i => mate[i]` directly — we must bind a throwaway `var pos_perm` just to pass `mut pos_perm`.
- **Goal it hurts:** express
- **Ideal code:**
  ```cp
  var ops = sort_perm([I] i => mate[i])
  ```
- **General fix:** Allow `var` (by-value mutable local copy) parameters in addition to `mut` (by-reference) parameters so callers can pass rvalues without a throwaway `var`.
- **Dream:** `dream/cf2062g.cp` line 33.
- **Severity:** low
