## No `a - b -> Int` distance on domain elements
- **Where:** `proto/ports/ecnerwala/cf2062g.cp:36`
- **What felt wrong:** Computing Manhattan distance between two elements of the same domain `I` requires `.ord` on every operand (`abs(i.ord - j.ord) + abs(p[i].ord - q[j].ord)`).
- **Goal it hurts:** express, hard-to-get-wrong
- **Dream:** `proto/ports/ecnerwala/dream/cf2062g.cp:32` (`abs(i - j) + abs(p[i] - q[j])`)
- **General fix:** Allow `a - b -> Int` on elements of the same ordered domain `D`.
- **Severity:** medium
- **Status:** open

## Passing a fresh working copy to a mutating helper requires a throwaway `var` and `mut`
- **Where:** `proto/ports/ecnerwala/cf2062g.cp:39-40,45-46`
- **What felt wrong:** `sort_perm` only mutates its own working copy, yet the caller must bind throwaway `var pos_perm` / `var val_perm` and pass `mut`.
- **Goal it hurts:** express
- **Dream:** `proto/ports/ecnerwala/dream/cf2062g.cp:35,40` (`sort_perm(mate)`, `sort_perm([I] v => q[pos_of[v]])`)
- **General fix:** Support by-value mutable parameters (`mut perm: [D]D`) when the caller passes an rvalue.
- **Severity:** low
- **Status:** open

## No single-cycle iterator `perm.cycle(from: r)` on `[D]D`
- **Where:** `proto/ports/ecnerwala/cf2062g.cp:21-25`
- **What felt wrong:** Finding the largest element `< r` in `r`'s cycle requires a 5-line `while cur != r` loop; `std.seq.perm_cycles` decomposes the whole permutation rather than one cycle from `r`.
- **Goal it hurts:** express
- **Dream:** `proto/ports/ecnerwala/dream/cf2062g.cp:21` (`let l = perm.cycle(from: r).filter(x => x < r).max()!`)

- **Severity:** low
- **Status:** open
