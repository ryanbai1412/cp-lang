Port and dream peel the permutation into decreasing layers with n queries (`layer: [Pos]?Int`), answer at once if a layer is longer than n, else walk back from an unlayered element through one element per layer. The port's `Pos.find(u => layer[u] == None)!` is the std predicate search the dream spells `Pos.first(…)`.

## The walk back is a `while` on `cur.prev!`
- **Where:** `while layer[cur] != j: cur = cur.prev!`.
- **Ideal code:** `cur = (..cur).rev.find(u => layer[u] == j)!`: a search with a visible end.
- **Why not changed:** the `while` keeps `cur` moving monotonically across the n layers, which is the point of the \(O(n^2)\) bound; the `find` form says the same but each call restarts its range at `cur`, so it is a wash. Left as is.
- **Severity:** low. **Owner:** idioms.
