# cplang

A competitive-programming language that compiles to C++, plus its toolchain.

- `plan/`: the source of truth for what we're building. Start with
  `plan/agent-context.md` and `plan/README.md`.
- `compiler/`: a course written for the user's education; not part of the handoff.
- `decisions.md`, `key-features.md`, `research/`: open decisions, proposals
  and the evidence behind them.
- `proto/`: the Python prototype compiler (partial; see agent-context.md).
- `corpus/`, `subs/`: the user's accepted C++ submissions, used for ports and
  benchmarks.
- `archive/`: superseded design docs.
