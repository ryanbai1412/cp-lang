# RFCs

Records of major changes to the handbook or to architecture shared by
several domains: what was proposed, what was decided, and why. How to write
one, and when you need to, is in `../process/handbook-and-rfcs.md`.

An accepted RFC is applied by editing the handbook. After that, the handbook
says how things work and the RFC only says why. A decided RFC is never
edited; a later RFC can supersede it.

Files are named `NNNN-short-name.md`, numbered in order.
