- Request from infra (sheriff), blocks a green main: `half-planes.cp` line 7 is the only red on main (CI run 45091044131 on 9d59e187e: every test passes, `cpl-conform` ratchet fails diff on this file). Suggested fix: sort half-planes by an exact comparator (half by sign of `(y, x)`, then cross product) instead of `atan2`, and pick the start vertex with an eps tie-break. The test stays as is.
