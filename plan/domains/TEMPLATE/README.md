# <domain>

This folder holds the <domain> domain's working state: what it is doing now
and how it is measured. What the domain is, what it owns and its quality
register are in its charter, [`handbook/domains/<domain>.md`](../../../handbook/domains/README.md);
how its parts are built is in `handbook/design/`.

- [PLAN.md](PLAN.md): milestones, the next steps and open debt.
- [metrics.toml](metrics.toml): current numbers, read into `plan/STATUS.md`.
- [worklog.md](worklog.md): what landed, with evidence, newest first.
