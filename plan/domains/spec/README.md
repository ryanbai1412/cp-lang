# spec

This folder holds the spec domain's time-bound work: [PLAN.md](PLAN.md) (what's
open, milestones and their exit criteria), [metrics.toml](metrics.toml)
(targets and today's numbers, with the commands that measure them),
[worklog.md](worklog.md), and measurements such as `delta/` and
[bugcatch.md](bugcatch.md). What the domain is, what it owns, its interfaces,
invariants and quality register are in the charter,
[handbook/domains/spec.md](../../../handbook/domains/spec.md).
