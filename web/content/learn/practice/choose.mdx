Answer q queries (1 ≤ q ≤ 2·10⁵). Each gives n and k (0 ≤ n, k ≤ 10⁶); print C(n, k), the number of ways to choose k of n items, modulo 10⁹ + 7. C(n, k) is 0 when k > n.

**Input:** q, then q lines `n k`. **Output:** q lines.

| Input | Output |
|---|---|
| `3`<br/>`5 2`<br/>`10 0`<br/>`3 5` | `10`<br/>`1`<br/>`0` |

<Judge id="choose">

- `type Z = Mod<1_000_000_007>` names the modular type once; every `+`, `*` and inverse on a `Z` reduces for you, so no `% MOD` is forgotten; see [`Mod`](/docs/ref/std/mod).
- `Comb<Z>(1e6)` builds the factorial and inverse-factorial tables once, in O(limit). Then `c.choose(n, k)` is O(1), and it is 0 when k > n.
- A `Z` prints as its value, so `print(c.choose(n, k))` is the whole answer.

</Judge>
