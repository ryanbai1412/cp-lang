You are given n numbers (1 ≤ n ≤ 2·10⁵, 1 ≤ aᵢ ≤ 10⁹) and a width k (1 ≤ k ≤ n). For every stretch of k consecutive numbers, from left to right, print its maximum.

**Input:** n and k, then the n numbers. **Output:** n − k + 1 integers on one line.

| Input | Output |
|---|---|
| `5 3`<br/>`1 3 2 5 4` | `3 5 5` |

<Judge id="window-max">

- Recomputing each maximum costs O(nk). `Window(max)` is a queue that keeps its maximum: `push` at the back, `pop` from the front, `all` for the fold, each O(1) amortized; see [`Window`](/docs/ref/std/window).
- Push every value; once the window holds more than k, pop one. From index k − 1 on, `w.all!` is the answer for the window ending there.
- Collect the answers in a list and `print` it once: a list prints space-separated.

</Judge>
