You are given n scores (1 ≤ n ≤ 2·10⁵, each from 1 to 10⁹). Print the largest score that is strictly below the maximum, or -1 if every score is the same.

**Input:** n, then n integers. **Output:** one integer.

| Input | Output |
|---|---|
| `5`<br/>`3 1 4 1 5` | `4` |

<Judge id="second-place">

- `a.filter(x => x < top)` keeps the values below the maximum, and `.max()` of what is left is a `?Int`: `None` when nothing is left, with no fake number for "no second place".
- `?? -1` puts the `-1` in one place: the output, where the statement asks for it. [Optionals](/learn/read/optionals) covers `?T`; a loop that only keeps a maximum is what the [loop_reduction](/lints/loop_reduction) lint flags.

</Judge>
