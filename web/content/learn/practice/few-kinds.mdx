You are given n numbers (1 ≤ n ≤ 2·10⁵, 1 ≤ aᵢ ≤ 10⁹) and k (1 ≤ k ≤ 2·10⁵). Print the length of the longest stretch of consecutive numbers that contains at most k different values.

**Input:** n and k, then the n numbers. **Output:** one integer.

| Input | Output |
|---|---|
| `7 2`<br/>`1 2 1 3 4 3 3` | `4` |

<Judge id="few-kinds">

- If a stretch has at most k values, so does every stretch inside it. So move the right end one step at a time, and move the left end only as far as needed: each end moves n times in total.
- A `Counter<Int, Int>` reads missing keys as 0, so `have.get(x) == 0` tells you a value is new and `have[x] += 1` counts it; see [`Counter`](/docs/ref/std/hashmap).
- [Greedy and two pointers](/learn/read/greedy-and-two-pointers) shows the window pattern.

</Judge>
