A tree has n vertices (1 ≤ n ≤ 2·10⁵) joined by n − 1 edges. Root it at vertex 1. For every vertex v from 1 to n, print the number of vertices in v's subtree, v included.

**Input:** n, then n − 1 lines `u v`. **Output:** n integers on one line.

| Input | Output |
|---|---|
| `5`<br/>`1 2`<br/>`1 3`<br/>`3 4`<br/>`3 5` | `5 1 3 1 1` |

<Judge id="subtree-sizes">

- `Rooted.new(Graph.undirected(es), V(1))` roots the tree at vertex 1 without recursion, so a path of 2·10⁵ vertices can't overflow the stack; see [trees](/docs/ref/std/tree).
- `t.subtree_sizes` is a `[V]Int`, one size per vertex, and an array prints space-separated.
- To compute it yourself, walk `t.order` backwards and add each vertex's size to its `t.parent(v)`.

</Judge>
