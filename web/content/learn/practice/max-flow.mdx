A pipe network has n junctions (2 ≤ n ≤ 500) and m one-way pipes (0 ≤ m ≤ 1000); pipe `u v c` carries up to c litres a second from u to v (1 ≤ c ≤ 10⁹). Print the most litres a second that can flow from junction 1 to junction n.

**Input:** n and m, then m lines `u v c`. **Output:** one integer.

| Input | Output |
|---|---|
| `4 5`<br/>`1 2 3`<br/>`1 3 2`<br/>`2 3 5`<br/>`2 4 2`<br/>`3 4 3` | `5` |

<Judge id="max-flow">

- `var g = FlowGraph<V>.new()` and `g.add(e.u, e.v, Some(e.c))` for each pipe; `None` would mean unlimited. See [flow](/docs/ref/std/flow).
- `g.max_flow(V(1), V(n))` runs Dinic and returns the value. It takes `mut self`, because the residual capacities change, which is why `g` is a `var`.
- Afterwards `g.min_cut(V(1))` tells which side of a minimum cut each junction is on, if a problem asks for the cut.

</Judge>
