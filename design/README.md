# design/

The language CP Lang is becoming. `plan/1x-*.md` describes what is
implemented; this directory is the target, and `DELTA.md` is the gap.

Read in this order: `ALIGN.md` (the goals and their tests), `spec/00-layers.md`
then the spec chapters by number, `CORE-ALIGN.md` (why the core mechanisms
look the way they do), and the exemplars (`EXEMPLARS.md`, `sketches/`) for
whole programs. `decisions-design.md` logs the calls made while drafting;
newer calls are in the root `decisions.md`. `spec/v2/` and `archive/` are
earlier drafts, kept for the reasoning; where they disagree with `spec/`,
`spec/` wins.
