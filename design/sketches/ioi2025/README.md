# IOI 2025 exemplars

Ideal CP Lang solutions to the six IOI 2025 tasks (Souvenirs, Triple Peaks,
World Map, Festival, Migrations, Obstacles for a Llama), written at the bar of
`design/EXEMPLARS-PORTS.md`. They use syntax and stdlib that may not exist yet
and have not been run. IOI tasks are graded through function signatures, so
`@grader` marks the entry points, with parameters typed by the statement's
bounds. Triple Peaks, Migrations and Obstacles follow the official
IOI 2025 model solutions; the other three follow accepted contestant code with
the same algorithms.
