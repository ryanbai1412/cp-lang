E0301: Wrong index domain

Nominal domains (`domain Row`, `domain Col`) are distinct types even when they have the same size. Index each axis with its own domain value.

Trigger:
domain Row = 1..=3
domain Col = 1..=3
let a: [Row]Int = 0
print(a[Col.first!])

Fix:
domain Row = 1..=3
domain Col = 1..=3
let a: [Row]Int = 0
print(a[Row.first!])
