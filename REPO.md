# REPO.md

Where everything lives, and where new things go. If you add a top-level
directory or move one, update this file in the same commit.

| Path | Holds |
|---|---|
| `AGENTS.md` | Start here: mission, goals, rules, reading order, commit convention |
| `README.md` | For people: what CP Lang is, install, quick start |
| `spec/` | The normative 0.3 language: `core/`, `lib/`, `tools/`, `std/` stubs, `diagnostics.md`, `conformance/`, `delta/`, gold dreams; `spec/README.md` is the index |
| `design/` | Design history: `spec/` (older chapters superseded by the top-level `spec/`), `GOALS.md` and `ALIGN.md` (goals and their tests), `CORE-ALIGN.md` (core mechanisms and the options weighed), `DELTA.md` (today vs the spec), exemplars and sketches, `archive/` (superseded drafts) |
| `decisions.md` | Every design call, its reason and how to reverse it; newest last |
| `plan/` | How we build it: `OPERATING.md` (settled decisions, the loop), `DOMAINS.md` (north star and status per domain), `STDLIB.md`, and the chapters `1x-*.md` describing the language as implemented |
| `crates/` | The compiler and toolchain in Rust, one crate per component; `cpl-cli` is the `cpl` binary |
| `stdlib/` | The standard library, written in CP Lang |
| `proto/ports/` | Accepted solutions ported to CP Lang, each gated against its C++ original by `gate.sh`; `<group>/dream/` holds each port's dream program (the solution as we want to write it, not compiled) |
| `corpus/`, `subs/` | Source material: `corpus/submissions/` (original submissions), `corpus/problems/<problem>/meta.json` per-problem records built and checked by `scripts/corpus.py` (see `corpus/README.md`); `corpus/statements/` is a git-ignored statement cache |
| `research/` | Evidence: `PORTS.md` (newest ports, generated by `scripts/ports-page.py`), `frictions/` (one report per port), `retros/` (why the loop changed), measurements |
| `docs/`, `site/` | User documentation, the website and the playground |
| `editors/` | Editor integrations: VS Code, JetBrains, Neovim, Emacs, Helix (`editors/README.md`) |
| `bench/`, `examples/` | Benchmarks against C++; small runnable programs |
| `scripts/` | `check.sh` (the gate), hooks, statement fetching, port picking |
| `tools/` | Standalone helper programs outside the main toolchain |
| `archive/` | Retired material kept for history |

Not tracked: `target/` and `dist/` (build output), `corpus/statements/`.

Planned moves, done between port waves so in-flight work doesn't conflict:
`proto/ports/` and `subs/` into `corpus/`, `decisions.md` into `design/`,
and the `plan/1x-*.md` chapters into `design/spec/` once reconciled.
