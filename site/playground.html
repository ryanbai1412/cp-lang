What runs here

The real CP Lang compiler and interpreter run locally in WebAssembly. Edit the source and standard input, run your program, or inspect its generated C++17. Diagnostics and cursor type information come from the same frontend as cpl.

Programs run in a worker with a five-second limit; Stop cancels a run. Browser recursion and memory limits are lower than the local toolchain. Design-only language features may report compiler diagnostics.

Keep the one-page cheat sheet handy, work through the interactive course, or press Trace to step through your own program in the trace debugger: every change to a top-level variable, every print and every debug(...), with the @brute(main) run beside it when the file has one.
