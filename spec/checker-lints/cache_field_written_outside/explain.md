An `@cache` field holds a value its type's methods derive from the other fields, like `Dsu.find`'s compressed `parent` (spec/core/05-ownership.md §10a). Its methods may write it through a read `self` because they keep it in step; code outside can write any value, and the next read then returns a wrong answer. Write it only from a method of the type, or drop `@cache` if it is plain state.
