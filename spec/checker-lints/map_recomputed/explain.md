`xs.map(f)` and `xs.filter(p)` are views: `sq[i]` calls `f(xs[i])` each time it is read, and each walk of a filter view tests every item again (R07.2.11). So a view indexed more than once, indexed under two loops, or walked inside a loop, comprehension or lambda pays for `f` on every read, not once per item. `List(xs.map(f))` computes every item once and makes each read plain; the fix-it writes it. An optional's `.map` is eager and never warns.
