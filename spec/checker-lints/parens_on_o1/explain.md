Parentheses mark work in CP Lang (decision 140): a member reads without `()` exactly when it is \(O(1)\), so `xs.len`, `xs.first`, `s.last` and `t.at` read like fields because they are. `xs.len()` is the C++ and Python spelling and is reported as error E0304 with a fix that drops the `()`; `cpl fix` applies it.
