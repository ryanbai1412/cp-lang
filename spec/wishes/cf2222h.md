# cf2222h wishes

## Library

- `Partitions(upto: Int)` (domain): every integer partition of `0..=upto`,
  interned as a dense index space. Build O(P * upto) time and memory, where
  P is the number of partitions (about 1.3e6 for `upto = 50`). Its elements
  `p: Partitions` have:
  - `p.parts -> List<Int>`: the parts in non-increasing order. O(1) view.
  - `p.size -> Int`: the sum of the parts. O(1).
  - `p.with(x: Int) -> Partitions`: `p` with one more part `x`; `with(0)` is
    `p`. O(1) table lookup; traps if the size leaves `0..=upto`.
  - `Partitions.of(xs: List<Int>) -> Partitions`: the partition with parts
    `xs` (any order, zeros dropped). O(len) by successive `with`.
  - `Partitions.empty`: the partition of 0.

  ```
  domain Shape = Partitions(upto: n)
  fn T(p: Shape) -> Shape = Shape.of(p.parts.runs().map(run => run.len))
  ```

  Why: the solution is a DP whose state is a multiset of multiplicities.
  Hashing a `List<Int>` per transition is too slow for 4e8 transitions;
  interning makes the state an ordinary domain, so `[Shape]Z`, `@memo` and
  `for p in Shape` all work unchanged.
