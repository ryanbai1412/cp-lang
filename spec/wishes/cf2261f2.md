# cf2261f2 wishes

## Library

- `fn print<R, C>(grid: [R, C]Bool, as: Str)`: prints one line per row,
  `as[0]` for false and `as[1]` for true, the output twin of
  `read(as: "01")`. O(|R| |C|).
- `fn chunks(self: Str, k: Int) -> List<Str>`: consecutive pieces of length
  `k` (the last may be shorter). O(len).

## Syntax

- A union of ranges as a type:

  ```
  let n: 3 | 10..=40 = read()
  ```

  Why: the statement allows exactly these values, and the special case
  `n == 3` is part of the problem. Without the union the type says
  `3..=40`, which admits inputs the algorithm was never built for.
