# cf2245h wishes

## Library

- `Walls<D>(blocked: [D]Bool)`: a line of cells, some of them walls. Build
  O(|D|) time and memory. Queries, each O(1) unless noted:
  - `run(i: D) -> Range<D>`: the maximal range around `i` holding no wall
    other than `i` itself (where a walk from `i` along the line can go).
  - `view(i: D) -> Range<D>`: the positions `j` with no wall strictly
    between `i` and `j`, which is `run(i)` plus the walls at its ends.
  - `arrivals(i: D) -> List<D>`: the walls whose `run` contains `i`: `[i]`
    if `i` is a wall, else the walls at the two ends of `view(i)` (at most
    two).
  - `stretches -> yields Range<D>`: the maximal ranges with no wall strictly
    inside; neighbours share their wall. O(|D|) in all.

  ```
  let in_row = [Row] r => Walls([Col] c => a[r, c] > 0)
  for r in Row, stretch in in_row[r].stretches: ...
  ```

  Why: every grid "walk straight until you hit something" problem rebuilds
  these four tables, with the same off-by-one at each end.

- `fn &(a: Range<D>, b: Range<D>) -> Range<D>`: the intersection, empty when
  they do not meet. O(1).

## Syntax

- Reading `m[k]` on a `var m: Map<K, V>` inserts `V`'s default, as
  `m[k] += 1` already does.

  ```
  var met: Map<Int, SortedBag<Col>> = {}
  pairs += met[a[w]].len - met[a[w]].count_range(known.start, known.end)
  met[a[w]].add(w.col)
  ```

  Why: a map of buckets is read and then grown at the same key. Making only
  `op=` insert forces a `get(k) ?? default` read beside a `[k]` write, which
  states the key twice in two ways.

- `a[r, c]` on `[Cell]T` with a named product `Cell = (row: Row, col: Col)`,
  as decision 2.5 makes `a[i, j]` sugar for `a[(i, j)]` on unnamed tuples.

  ```
  type Cell = (row: Row, col: Col)
  let a: [Cell]0..=2e6 = read()
  Walls([Col] c => a[r, c] > 0)
  ```

  Why: the cells are named `(row, col)` so `w.row` and `w.col` read
  plainly, and the table built from one row still indexes positionally.
