# cf2229h wishes

## Library

- `fn before(self: D) -> D.bounds` on a position domain: the cut just
  before position `i`, the counterpart of `i.after`. O(1).

  ```
  evenable(x..j.before)
  ```

  Why: the gap between a cut `x` and a kept position `j` is a range of cuts;
  without `before` it is spelled with raw `+ 1`/`- 1` arithmetic.

- `fn flatten<D, T>(self: [D]?T) -> List<T>`: the present values in index
  order. O(|D|).

- `Prefix<D, Bool>` counts: `sum` and `prefix` return the number of true
  entries as an `Int`. O(1) per query, as for any `Prefix`.

  ```
  let ones = Prefix(s.map(ch => ch == '1'))
  ones.sum(gap) % 2 == 0
  ```

  Why: counting the positions with a property is the most common prefix
  sum; wrapping each test in `if c: 1 else: 0` restates it as arithmetic.

## Syntax

- `domain Cut = Pos.bounds` is `Bounds<Pos>`, so a `Cut` goes wherever a
  `Bounds<Pos>` is taken (`ones.prefix(x)`), and a range of cuts converts
  to the positions between them where a `Range<Pos>` is expected (the
  brief's decided spelling).

  ```
  fn evenable(gap: Range<Pos>) -> Bool = ...
  evenable(x..j.before)
  ```

  Why: the gap between two cuts is a run of positions; spelling the
  conversion by hand brings back the `+ 1` the domains exist to remove.

- `@memo` over a fixed-size array of domain values, `[Side]?Cut` with
  `Side = 0..2`, packs flat as the product `(?Cut, ?Cut)` does.

  ```
  type Reach = [Side]?Cut
  @memo fn words(at: Reach) -> Z
  ```

  Why: the state is "the earliest live cut on each side", which reads as an
  array over `Side`. Spelling it as a pair `(even: ?Cut, odd: ?Cut)` instead
  makes `reach` and `read_char` branch on the side by hand. The key space,
  `(n + 2)^2 <= 2^24`, is the same either way.
