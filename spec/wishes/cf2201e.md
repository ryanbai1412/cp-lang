## Library

    pub fn correlate(a: List<Int>, b: List<Int>, cyclic: Bool = false) -> List<Int>
        // c[k] = sum over j of a[j + k] * b[j] (indices mod n when cyclic); O(n log n) by NTT
    pub fn prime_factors(x: Int) -> List<Int>
        // the distinct primes dividing x, ascending; O(sqrt x), or O(log x) with a sieve
    pub fn sum<T>(self: Iterable<E>, f: E -> T) -> T
        // sum of f over the items, T's own `+` and 0; O(len) calls
    pub fn product<T>(self: Iterable<E>, f: E -> T) -> T
        // product of f over the items, T's own `*` and 1; O(len) calls

`correlate` is `convolve` with the second argument reversed. It gets its own
name because "how well does a shifted copy of a agree with b" is the common
use and the reversal plus index bookkeeping is exactly where contestants slip.
`prime_factors` is `factor(x).map(.0)`, named because the distinct-prime set is
what multiplicative weights (`phi`, `prod (1 - p)`, Möbius over divisors)
iterate over.
