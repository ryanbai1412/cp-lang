## Library

    pub fn subsets<T>(self: Range<T>) -> Gen<Set<T>>                // every subset, in binary-counter order; O(2^n) to exhaust, O(n) per subset
    pub fn random_subset<T>(r: Range<T>) -> Set<T>                  // each element kept independently with probability 1/2, from the run's seeded rng; O(n)
    pub fn cycle_count(self: List<Int>) -> Int                      // cycles of a permutation of 1..=len; O(len)
    pub fn ++<T>(a: Seq<T>, b: Seq<T>) -> List<T>                   // concatenation into a new list; O(a.len + b.len)
    pub fn list<T>(self: Seq<T>) -> List<T>                         // collect; O(n)

`subsets` already appears on domains (`Query.subsets(size: ..=2)`); this
asks for the same generator on plain ranges, without a size filter.
