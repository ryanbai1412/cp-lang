# cf2245d1 wishes

## Library

- `Sym<D>` (domain): the unordered pairs `{u, v}` of `D`, `u <= v`, as an
  index space. `[Sym<D>]T` stores `|D| (|D| + 1) / 2` values; `t[u, v]` and
  `t[v, u]` name the same slot; `for (u, v) in Sym<D>` yields each pair once
  with `u <= v`. O(1) index, O(|D|^2) memory and iteration.

  ```
  var fine: [Sym<V>]Bool = false
  for (o, i, j) in read<[m](1..=2, V, V)>(): fine[i, j] = o == 1
  ```

  Why: the input restricts unordered pairs. A plain `[V, V]Bool` needs both
  `fine[i, j]` and `fine[j, i]` written (forgetting one is a silent wrong
  answer) or a `min`/`max` wrapper on every read.
