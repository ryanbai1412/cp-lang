    pub fn floor_index<T: Ord>(self: List<T>, x: T) -> ?Int        // last index whose element is <= x in a sorted list (binary search); O(log n)
    pub fn floor<T: Ord>(self: List<T>, x: T) -> ?T                // the element at floor_index; O(log n)
    pub fn memo<A, R>(f: A => R) -> A => R                         // cache f by argument; each distinct argument evaluates f once; O(1) expected per call

`floor` returns an optional, and `lost.floor(n) == n` compares it with a
plain value, which is false for `none`.

## Syntax

Nested `fn` that captures enclosing locals (`pin` reads `h`, `ban` and
`lost`; `wins` reads `lost` while it grows):

    fn wins(h: Int, ban: ?Int) -> Bool:
        fn pin(q: Int) -> Bool: ...

Reason: the recursion is the editorial's, and lifting `pin` and `wins` to
top level would thread `m`, `mid` and `lost` through every call.
