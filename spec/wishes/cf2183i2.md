# cf2183i2 wishes

## Library

    pub fn chain<T>(self: Iterable<T>, rest: Iterable<T>) -> Iterable<T>
        // the items of self, then the items of rest; lazy, O(1) to build
    pub fn find<T>(self: Iterable<T>, f: T -> Bool) -> ?T
        // the first item satisfying f, or none; stops there, O(index) calls

`find` already exists on `Str` and `Bitset`; this is the same name on every
iterable. `chain` reads two disjoint ranges as one search space (`(x..=l).chain(r..=y)`
is the frame minus the gap) without allocating a list for it.

## Syntax

none. `t[k][s] ??= Skip` is the decided `x op= y` with `??` (as in agc079c);
`enum Step: Skip, At(Int)` and `if let At(i) = e` are the decided payload enums
(as in cf2022c and cf2178h).
