A counter that grows on matching elements and resets to `0` on the others is a run-length scan, and it needs a second copy of its body after the loop for the last run, which is the line newcomers forget. `xs.runs()` from `std.seq` yields every run as `(val, len)`, the last one included, so the work happens once per run. There is no automatic fix, since what is done with each run varies.
