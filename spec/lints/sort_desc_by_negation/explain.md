C++ sorts descending with `greater<>()` or by negating the key, and code translated from it writes `xs.sorted(by: x => -x)`. Negating the key hides the intent and overflows on the smallest value of the type. `sort` and `sorted` take `desc: true`, which reverses the order with the key unchanged. The fix applies when the key is exactly the negated element; for a negated field or expression, the help suggests keeping the key and adding `desc: true`.
