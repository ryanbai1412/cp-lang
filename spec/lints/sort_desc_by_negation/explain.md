C++ sorts descending with `greater<>()` or by negating the key, and code translated from it writes `xs.sorted(by: x => -x)`. Negating the key hides the intent and overflows on the smallest value of the type. `desc(k)` (`std.algebra`) wraps a key so it compares in reverse, with the key unchanged: `xs.sorted(by: x => desc(x))`. The fix replaces the negation with `desc(..)`, for the element and for a field or expression alike.
