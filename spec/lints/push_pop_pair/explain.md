`h.push(x)` and then `h.pop()!` sifts the new element up and then the root down, and the `!` asks a question whose answer is known: the heap can't be empty just after a push. `h.push_pop(x)` (`std.heap`) does both in one sift and returns the smaller of `x` and the old top, so `x` itself comes back in \(O(1)\) when it is no greater than the top. The result is the same, so the fix is mechanical.
