A C++ breadth-first search keeps its queue in a vector and a head index that walks it: `while head < q.len: let u = q[head]; head += 1`. `bfs(next, from: [s])` from `std.graph` runs that queue and returns the distances, the parents and the visit order. A queue run by hand for anything else is a `Deque` with `push` and `pop_front()`, which says which end each step uses. There is no automatic fix, since what the loop computes decides which result replaces it.
