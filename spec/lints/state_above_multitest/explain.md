A `var` declared above `@!multitest` is shared by every test case, and a test that writes it (`acc += x`, `best = v`) leaves its value for the next one: the first test passes and the later ones read stale state. Declare the variable below `@!multitest`, where each test gets a fresh one. A counter stepped by a constant (`k += 1`, for `Case #k`) is meant to carry over and is not flagged.
