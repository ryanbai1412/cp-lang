A range check written as two comparisons joined by `and` names its variable twice and splits the range. CP Lang chains comparisons as Python does, each operand evaluated once: `0 <= x < n` reads as the range it checks. For a grid cell checked in both coordinates, give the coordinates their domains instead: `p.adj4` from `std.grid` yields only the neighbours inside the grid. The quick fix chains the comparisons that share a name, also inside a longer `and` (`0 <= lo and lo <= hi and hi <= n` is `0 <= lo <= hi <= n`); bounds written the other way round are reordered only when neither calls anything.
