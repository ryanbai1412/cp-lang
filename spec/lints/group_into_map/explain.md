A loop whose only statement is `(m[k] ??= []).push(v)` sorts elements into lists by a key: `xs.group(by: x => k, of: x => v)` (`std.seq`) builds the same `HashMap<K, List<V>>` in one expression, \(O(n)\) expected, each list in input order, with no empty-list default to write. Leave out `of:` when the element itself is pushed. When the key is a domain position, `xs.map(k).buckets()` gives a `[D]List` instead of a map. A loop that reads the map while filling it, or pushes only under a condition, is not reported. There is no automatic fix, because `group` returns a `HashMap` and a `Map` the rest of the file walks in key order has to stay one.
