Copying a contiguous slice `xs[l..r]` into a temporary `List`, sorting/reversing/rotating it, and writing the elements back into `xs[l..r]` allocates an unnecessary copy. Mutable slice views lend `xs[l..r]` in \(O(1)\) via `IndexedMut`, so `xs[l..r].sort(...)` / `.reverse()` / `.rotate_left(...)` runs in place with no copy. `cpl fix` rewrites the copy-mutate-writeback sequence when the temporary is not read afterward.
