`best = max(best, x)` and `if x > best: best = x` write the place twice, and the copies must agree (`best[i] = max(best[j], x)` is a different statement that looks the same). CP Lang spells the update once: `best max= x`, `lo min= x`. The fix applies when nothing in the statement calls anything, so it evaluates exactly what the original did, and only on a place the checker types as a number, a `Char` or a position. On a list or a tuple `min=` works elementwise while `<` compares lexicographically, so `if rot < best: best = rot` keeps its `if`.
