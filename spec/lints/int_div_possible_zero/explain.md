`a / b` and `a % b` trap (R0203) when `b` is 0. When the declared bounds let `b` be 0, some valid input makes the program trap. Either that input is real and needs its own branch (`if b != 0:`), or the range was written too wide and should exclude 0 (`1..=hi`), so the type says what the statement promises. Conditions the program already tests, such as `if b > 0:`, narrow the range and silence the lint.
