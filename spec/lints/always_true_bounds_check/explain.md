A declared range is a promise: `let n: 1..=10 = read()` traps on any other input, so after it `n >= 1` always holds and `n == 0` never does. A test the bounds settle is either noise, or a sign the range is tighter than the statement, so the case it guards was meant to happen. Drop the test or dead branch, or widen the declaration to what the statement allows. The lint looks only at one comparison of declared inputs and literals, uses the tests around it (`if l < r:` narrows `l` and `r`), and skips `@alt`, `@check` and `@gen` functions.
