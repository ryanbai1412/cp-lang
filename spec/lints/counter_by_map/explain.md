A `Map<K, Int>` that is only ever bumped with `cnt[x] = (cnt.get(x) ?? 0) + 1` is a counter written by hand: every update repeats the key and the `?? 0`. `Counter<K>` (`std.hashmap`) is the counter itself: `var cnt = Counter<K>(0)` starts it, `cnt.push(x)` adds 1, `cnt.add(x, d)` adds `d`, and `cnt[x]` reads 0 for a key it never saw, all \(O(1)\) expected. It is hashed, so keep the `Map` when you walk the counts in key order.
