A `Map<K, Int>` that is only ever bumped with `cnt[x] = (cnt.get(x) ?? 0) + 1` is a counter written by hand: every update repeats the key and the `?? 0`. `Counter<K>` (`std.hashmap`) is the counter itself: `var cnt = Counter<K>()` starts it, `cnt.push(x)` adds 1, `cnt.add(x, d)` adds `d`, and `cnt[x]` reads 0 for a key it never saw, all \(O(1)\) expected. A fresh map whose only write is `for x in a: cnt[x] += 1` is the same counter, and when that loop is the whole fill, `let cnt = a.tally()` (`std.seq`) is the count in one call. A sorted `Map` costs a tree walk per bump, so this is also the faster program. It is hashed, so keep the `Map` when you walk the counts in key order; the lint stays quiet when the map is read with `.first`, `.last` or `.range`.
