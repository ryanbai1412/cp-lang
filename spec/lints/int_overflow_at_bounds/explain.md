`Int` is 64 bits, and leaving it traps (R0202). When the declared ranges of an expression's operands let its value leave `Int`, as `a * b` does with `a: 0..=10^12` and `b: 0..=10^9`, the lint names an input in those ranges for which it does, found and checked by the prover. Widen one operand, `I128(a) * b`; if the statement asks for the answer modulo a prime, compute in `Mod<P>`; or, if the statement bounds the values more tightly, declare that. Only the innermost such expression is reported, and `@alt`, `@check` and `@gen` functions, which run on small generated inputs, are skipped.
