C++ code tests `m.count(k)` before incrementing so the first insert is explicit. On a CP Lang `Map`, `m[k] op= v` starts a missing key at the default of the value type (`0` for numbers), so `m[k] += v` is the whole step: the test and the `else` branch say the same thing twice. For counting a whole sequence, `xs.tally()` builds the counts in one call. There is no automatic fix yet, because the rewrite is only right when `m` is a `Map`.
