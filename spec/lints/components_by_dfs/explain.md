Starting a search from every vertex not yet seen and counting the starts counts connected components, with a `seen` list, a recursive visit and the counter written by hand (and recursion deep enough to overflow on a path). `components(adj)` from `std.graph` returns the component domain `C` and `comp[v]` for every vertex: `C.count` is how many there are, and `comp[u] == comp[v]` asks whether two vertices are connected. There is no automatic fix, since the graph has to be typed over a domain first.
