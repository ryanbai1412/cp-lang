Marking a vertex 1 when the DFS enters it and 2 when it leaves, and calling an arc into a vertex still marked 1 a cycle, is the three-colour test for a directed cycle. Written by hand it needs the colour list, a flag set from inside the recursion, and recursion deep enough to overflow on a long path. `find_cycle(g)` from `std.graph` runs the same test without recursion and returns the cycle itself (`None` when there is none), so `find_cycle(g) != None` asks the question and the cycle is there when the answer needs it. When the real question is an order, `topo(g)` returns one or `None`. There is no automatic fix, since the graph has to be typed over a vertex domain first. A two-colouring for bipartiteness (`paint(v, 3 - c)`) is a different test and is not reported.
