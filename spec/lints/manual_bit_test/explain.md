C++ tests bit `i` of `x` with `(x >> i) & 1` or `x & (1 << i)`, compared against `1` or `0`. CP Lang names the operation: `x.bit(i)` is `true` when bit `i` is set, for every `i` (bits past 63 read the sign), so the shift, the mask and the comparison collapse into one call that says what it tests. The fix rewrites the comparison to `x.bit(i)`, or `not x.bit(i)` when it tests for a clear bit. A subset loop over `0..(1 << n)` usually also wants `std.bits` subset iteration.
