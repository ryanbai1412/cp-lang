C++ reads the test count in `main` and wraps the solution in `while (t--)`. CP Lang writes the case boundary once: `@!multitest` on its own line reads the count and runs everything below it per case, and code above it (a sieve, a factorial table) runs once. The body loses a level of indentation, single-test and multitest files read the same, and switching a file between the two is one line. The fix replaces the count's `let` and the loop header with the divider and unindents the body. It does not fire when the body `return`s, which under the divider would end only the current case, or `break`s or `continue`s the case loop, or uses the count.
