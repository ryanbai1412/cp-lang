C++ walks every unordered pair with two loops, the inner one starting at `i + 1`. `pairs()` from `std.seq` yields each pair `(x, y)` with `x` before `y` once, so `for (x, y) in a.pairs()` says it without index arithmetic; `(0..n).pairs()` gives the index pairs when the body needs positions. There is no automatic fix, because the body has to change from `a[i]` and `a[j]` to the pair's names.
