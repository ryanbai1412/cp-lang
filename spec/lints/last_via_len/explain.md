C++ reads the last element as `v[v.size() - 1]` or `v.back()`. CP Lang's `.last` is the last element as an optional, `none` on an empty list, and `.last(k)` is the one `k` before it; `xs.last!` reads it and traps on an empty list exactly as the index would. The fix applies to reads; a write `xs[xs.len - 1] = v` keeps the index.
