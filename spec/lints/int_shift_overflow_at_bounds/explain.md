`1 << k` fits in an `Int` only while `k` is at most 62; at 63 it overflows and traps (R0202). When the declared range of `k` reaches past the safe shift, the largest valid input traps. If the statement keeps `k` smaller, declare that range, so the type says what the statement promises. If the value really needs bit 63, shift a `U64` (`U64(1) << k`), or keep a set of bits in a `Bitset` from `std.bitset`.
