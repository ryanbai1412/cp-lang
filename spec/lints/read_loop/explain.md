A loop that reads one item and pushes it, `m` times, is the input format written out by hand. `let edges: [0..m](1..=n, 1..=n) = read()` reads all `m` items at once: the type says how many there are and what bounds each one has, so the bounds are checked as the input is read and the list's length is known. Declare it `var` if the list changes later. A loop that pushes something other than what it read, such as `(u - 1, v - 1)`, is not reported, because the read value and the stored value differ. There is no automatic fix, because the item type has to be read from the problem statement.
