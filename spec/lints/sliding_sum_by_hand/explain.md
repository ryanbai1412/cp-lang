Keeping `cur` as the sum of the last `k` elements with `cur += a[i] - a[i - k]` needs a separate first loop for the first window and an index shift to get right at both ends. `let p = Prefix(a)` (`std.prefix`) answers the sum of any window in \(O(1)\) after \(O(n)\) setup: `p.fold(j - k..j)` is the window that ends just before `j`, so the windows are `j` in `k..=n` and the best one is `(k..=n).map(j => p.fold(j - k..j)).max()!`. Every window sum is then a read, with no state carried between iterations. A running difference of two different sequences is not reported. There is no automatic fix, because the running sum is read inside the loop that maintains it.
