A range only counts up: `n..0` holds every `i` with `n <= i < 0`, and when `n` is at least 1 there is none, so the loop body never runs. This is the C++ `for (i = n; i > 0; i--)` written as a range. To count down, reverse the range you mean: `(0..n).rev` runs `n - 1` down to `0`, and `(0..=n).rev` runs `n` down to `0`. The lint fires only when the declared bounds prove the start is above the end for every input.
