The prelude (`std/prelude.cp`) brings in each of its names when a program uses it, so `use std.tree.{Rooted}` or `use std.mod.Mod` says nothing. `cpl fix` drops the name, and the `use` when nothing is left. An alias, a glob, a `pub use` and the imports of a library (a file with `pub` items) are left alone.
