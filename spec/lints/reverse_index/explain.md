`[xs[xs.len - 1 - i] for i in 0..xs.len]` spells out the reversal index by index; the `- 1` and the bound must both be right. `xs.reversed()` says it in one word, costs the same \(O(n)\) and allocates the same new list. The fix applies when the copy runs over the whole list (`0..xs.len`), `xs` is a plain name or field, and the checker types it as a `List`; a `Str` is left alone because `s.reversed()` is a `Str`, not a list of characters. To walk backwards without a copy, use `xs.rev`.
