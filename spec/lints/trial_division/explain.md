Trial division up to \(\sqrt{x}\) (`while d * d <= x: if x % d == 0: ...`) is the textbook way to list divisors or prime factors, and the loop bound, the square-root pairing and the leftover prime are each easy to get wrong. `divisors(x)` lists the divisors and `factor(x)` returns the `(prime, exponent)` pairs, both from `std.math`. A loop with an inner `while x % d == 0` is reported as factoring, otherwise as listing divisors. There is no automatic fix, since what the loop computes from them varies.
