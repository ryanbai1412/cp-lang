A `while lo < hi` loop that halves with `let mid = (lo + hi) / 2` and sets `hi = mid` / `lo = mid + 1` (or `lo = mid` / `hi = mid - 1` with the rounded-up midpoint) on a predicate of `mid` is `r.first_true(ok)` (or `r.last_true(ok)`) on its range: O(log n) calls of the predicate, no off-by-one in the bounds, and the same midpoint that cannot overflow. `cpl fix` rewrites the loop and its `var (lo, hi)` when `hi` is not read after it. The predicate must be monotone along the range, which the loop already assumes.
