C++ takes a number apart with `while (y > 0) { d = y % 10; y /= 10; }`. `x.digits()` from `std.math` is the list of digits, lowest first (`x.digits(base: b)` in another base), so a digit sum is `x.digits().sum()` and any other per-digit work is a `for d in x.digits()` loop over a value that is never mutated. There is no automatic fix; base 2 is left alone, where `bit` and `std.bits` are the better spelling.
