C++ starts "the index found so far" at `-1` and "the best so far" at `-1e18`, because an `int` has no value for "nothing yet". Both are real numbers: `-1` indexes from the end in Python habits and passes any `>= -1` test, and `-10**18` is only a guess at a bound the data may pass. CP Lang has the value C++ lacks: `var found: ?Int = None` starts with nothing, `found = i` sets it, and the reader must say what nothing means (`found ?? -1`, `if let`, `!`). For a running best, `a.max()` or `.min()` from `std.seq` returns `?T` and needs no start at all.

The lint fires on a scalar `var` started at `-1` and later set to a name inside a `for` loop, or started at a value of size at least `10**9` and set inside a `for` loop. A `while` loop's bound (`var hi = 10**18` in a binary search) is not a sentinel and is left alone. It has no fix, since each read of the variable changes.
