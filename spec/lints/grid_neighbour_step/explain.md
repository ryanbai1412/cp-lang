In C++ a grid is `vector<vector<int>>` indexed by plain ints, so every neighbour read needs its own edge test: `if (r > 0) ways[r][c] += ways[r - 1][c]`. Each test is one more place for an off-by-one, and nothing ties `r > 0` to the `r - 1` it protects. In CP Lang a grid is an array over two domains, `[Row, Col]T` with `domain Row = 0..h`, and `(r, c).step(Dir4.up)` from `std.grid` is the cell one step up or `None` when that step leaves the grid. `if let (pr, pc) = (r, c).step(d):` reads the neighbour only when it exists, so the edge test is gone, and `Dir4.left`, `Dir4.down`, `Dir8` work the same way.

The lint fires on `if r > 0:` (or `r >= 1`) whose body indexes a grid of two or more indices at `r - 1`. It has no fix, since the grid's declaration changes too.
