C++ reads a stack with `.back()` and then drops it with `.pop_back()`, because `pop_back` returns nothing. A CP Lang `List.pop()` returns the element it takes (`None` when empty), so `let x = s.last!` followed by `s.pop()` is one step: `let x = s.pop()!`. Both trap on an empty list. The fix applies when the list is code that calls nothing (a name, field or index path) whose type is `List`, and the two lines are adjacent. std declares it with `@lint` on `last` (`std/seq.cp`).
