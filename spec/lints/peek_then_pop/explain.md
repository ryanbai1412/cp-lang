C++ reads a stack with `.back()` and then drops it with `.pop_back()`, because `pop_back` returns nothing. A CP Lang `List.pop()` returns the element it takes (`none` when empty), so `let x = s.last!` followed by `s.pop()` is one step: `let x = s.pop()!`. Both trap on an empty list. The fix applies when the list is a plain name or field path whose type is `List`, and nothing stands between the two lines.
