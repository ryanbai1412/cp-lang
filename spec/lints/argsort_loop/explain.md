Sorting pairs `(a[i], i)` is how C++ gets the positions of `a` in order of value: the pair carries the position along, and the sort's tie-break on the second half keeps equal values in position order. `(0..n).sorted(by: i => a[i])` says the same thing directly: sort the positions, keyed by their value. `sorted` is stable, so equal values keep position order exactly as the pairs did, and the result is a list of positions, so the loop over it has no `(v, i)` to unpack and reads `a[i]` where it needs it. The cost is the same \(O(n \log n)\). Pairs whose second half is not the position, such as `(a[i], b[i])`, are a real sort of pairs and are not reported. There is no automatic fix, because the code that reads the sorted pairs has to change with them.
