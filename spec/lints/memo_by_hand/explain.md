A map declared beside a recursive fn, read with `if key in memo: return memo[key]` at the top and written before each `return`, is memoization by hand: three places that must agree on the key. `@memo(map)` on the fn says it once, and `@memo(array)` stores a dense table when every parameter has a bounded type (a domain, a range, `Bool`). The finding is on the map's declaration. There is no automatic fix, because every store has to be removed with it.
