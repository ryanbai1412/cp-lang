A `Map<K, Int>` whose entries go up by one and down by one, with the decrement guarded by `cnt[x] > 0`, is a multiset kept by hand, C++'s `map<int, int>` with `cnt[x]++` and `cnt[x]--`. `SortedBag<K>` (`std.bag`, in the prelude) is that multiset: `bag.add(x)` adds a copy, `bag.remove(x)` removes one and is `false` when there is none, `bag.count(x)` is the number of copies, and `bag.first` / `bag.last` are the smallest and largest, which the map can only find by scanning. A counting map that only goes up (a frequency table) is not reported. There is no automatic fix, since the reads of the counts change with the type.
