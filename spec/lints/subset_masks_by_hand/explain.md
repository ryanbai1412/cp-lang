Walking `mask` over `0..(1 << n)` and testing `(mask >> i) & 1` to pick `a[i]` enumerates every subset of `a`, one bit at a time: \(O(2^n \cdot n)\), with a shift, a mask and a bit test to get right. `for sub in a.subsequences()` (`std.seq`) walks the same subsets with `sub.items` the chosen elements, in \(O(k)\) per subset, and `sub.prune()` skips every extension of the current one, which a mask loop cannot do. Keep the mask where it is itself the answer or a DP index (`dp[mask]`); a loop over masks that never picks elements by bit is not reported. There is no automatic fix, because whether the mask is still needed has to be read.
