Comparing `s[i]` with `s[n - 1 - i]` for every `i` in `0..n / 2` is the palindrome test, written with a mirrored index and a half-length bound that are each easy to get wrong by one. `is_palindrome(s)` (`std.strings`) is that test: \(O(n)\), stops at the first mismatch, and works on any `Indexed` sequence, so a `List<Int>` or an array is tested the same way as a `Str`. Comparing one sequence against the mirror of another, `s[i] == t[n - 1 - i]`, is a different question and is not reported. There is no automatic fix, because the loop usually sets a flag or breaks, and the code that reads it has to change with it.
