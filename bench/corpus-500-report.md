## Files against problems

The 971 files are not 971 solved problems. 91 are regression ports that `proto/run_all.sh` stresses on every change. 531 are runnable scout ports, the form a batch harness builds. 298 are spec-form files: the same solutions written against the locked spec, which no implementation accepts yet, so each has a runnable twin in `today/`. 44 are blind-critic first drafts or superseded `before/` versions, and 7 are shared modules and a bug repro rather than ports.

After grouping by problem code, 351 problems have more than one file and 50 were ported independently in more than one directory (parallel scout batches landing the same pick, or a scout sketch that later graduated to a regression port). The registry keeps one canonical port per problem: a port with a passing harness run beats one without, then regression beats runnable beats spec, then the newer spec generation, then the shorter file. Every other file is listed under that problem's `duplicates`.

The most re-ported problems: `dpz` (blind_critic_2, scout_batch_17, top-level).

## Line counts

Blank and comment-only lines never count. "Stripped" removes from the original what a perfect C++ contest library would have supplied: the template, the I/O driver and standard data structures.

Over the 579 canonical ports that have a measured original, the median original is 100 lines raw and 65 stripped, and the median port is 32 lines (means: 119.2, 77.7 and 40.9). Per port, the median reduction is 68.9% raw and 47.3% stripped (means 65.8% and 44.0%). 30 ports are no shorter than their stripped original.

Restricted to the 566 canonical ports with a passing harness run, the numbers are 65.6% raw and 47.1% stripped (23310 lines against 67692 and 44048). This is the number to quote: every line in it compiled and agreed with the original.

The 298 spec-form files are shorter still: 73.3% raw and 60.0% stripped (9683 lines). The runnable ports of 290 of those problems take 13434 lines (43.0% stripped), so the gap between the spec and what builds today is the difference between those two figures. Spec-form numbers are a design target, not a measurement of working code.

How the stripping was done: 91 canonical ports have hand-written `.strip` ranges, and those are used as they are. For the rest, `auto_strip` removes the template, the driver, generic (`template`) types and top-level code whose name is a library name (`DSU`, `binpow`, `SparseTable` and so on). On the 91 regression ports that have hand-written ranges, the heuristic leaves 4113 lines where the hand ranges leave 3542 (+16.1%), matching exactly on 45 and within five lines on 62. It misses library code with a problem-specific name, so auto-stripped reductions lean high.

// TSOC '15 Contest 2 #6: n soldiers in a row with health values, and q
// volleys. Each volley takes x from every soldier in l..=r; after it, print
// the lowest health in l..=r and the lowest in the whole row, where a
// soldier below 0 counts as 0.
//
// Range add, range min: a lazy tree and two folds per volley.

let (n, q): (Int, Int) = read()
domain Soldier = 1..=n
let health: [Soldier]Int = read()

var row = LazySegTree<Soldier, Int, Int>(AddMin, health)
for _ in 0..q:
    let (l, r, x): (Soldier, Soldier, Int) = read()
    row.apply(l..=r, -x)
    print(max(row.fold(l..=r), 0), max(row.all, 0))

**`ioi14p2`** ([`proto/ports/scout_batch_2/ioi14p2.cp`](../proto/ports/scout_batch_2/ioi14p2.cp)): 12 lines against 99 raw and 74 stripped in [`4843911.cpp`](../corpus/submissions/4843911.cpp).

```
// IOI 2014 Wall: n columns of height 0 and k operations in order. "add"
// raises every column of a range that is below h up to h; "remove" lowers
// every column above h down to h. Print the final heights.
//
// Both operations clamp a height to an interval, and clamps compose into a
// clamp. So this is a range update with no range query: push the clamps
// down a lazy tree and read each leaf at the end.
use std.algebra.{Action}
use std.lazy.{LazySegTree}

let (n, k): (Int, Int) = read()
domain Col = 0..n

type Clamp = (lo: Int, hi: Int)
fn clamp(c: Clamp, h: Int) -> Int = min(max(h, c.lo), c.hi)
let clamps = Action<Int, Clamp>((lo: 0, hi: Int.MAX), (f, g) => (lo: clamp(f, g.lo), hi: clamp(f, g.hi)), (f, h, len) => clamp(f, h), over: max)

var wall = LazySegTree<Col, Int, Clamp>(clamps, [Col] c => 0)
for _ in 0..k:
    let (op, l, r, h): (Int, Col, Col, Int) = read()
    wall.apply(l..=r, if op == 1: (lo: h, hi: Int.MAX) else: (lo: 0, hi: h))
for c in Col: print(wall.get(c))
```

// CTSC 2006 Singing Kingdom: letters 1..m are drawn uniformly at random until
// a given name appears as a block of consecutive draws. Print the expected
// number of draws modulo 10^4, as four digits, for each of t names.
//
// The original solves a recurrence over the failure function. The closed
// form is shorter: the expected wait is the sum of m^b over every border b
// of the name, the whole name included (a border is a prefix that is also a
// suffix).
// original: corpus/submissions/4528855.cpp
use std.strings.{prefix_function}
use std.mod.{Mod}

let (m, t): (Int, Int) = read()
type Z = Mod<10000>

fn digit(x: Int) -> Str = "0123456789"[x % 10..x % 10 + 1]

for _ in 0..t:
    let n: Int = read()
    domain I = 0..n
    let name: [I]Int = read()
    let border = prefix_function([name[i] for i in I])
    var (wait, b) = (Z(0), n)
    while b > 0:
        wait = wait + Z(m).pow(b)
        b = border[b - 1]
    let w = wait.v
    print(digit(w / 1000) + digit(w / 100) + digit(w / 10) + digit(w))
```

// CCO 2017 P5 Professional Network: person i becomes your friend for free once
// you have `need` friends, or at any time for `price`. Befriend all n people
// as cheaply as possible.
// original: corpus/submissions/4575278.cpp
let n: 1..=2e5 = read()
let people: [n](need: 0..=n, price: 1..=1e9) = read() where all(p.need <= n for p in people)

var by_need: [0..=n]List<Int> = []
for p in people: by_need[p.need].push(p.price)

// From the most demanding down. `waiting` holds the people who want k friends
// or more and are not paid for. They cannot help each other reach k, so the
// other n - waiting.len() people have to be k at least; while they are not,
// the cheapest of those waiting is paid.
var waiting = MinHeap<Int>()
var paid = 0
for k in (0..=n).rev:
    for price in by_need[k]: waiting.push(price)
    while n - waiting.len() < k: paid += waiting.pop()!
print(paid)
```
